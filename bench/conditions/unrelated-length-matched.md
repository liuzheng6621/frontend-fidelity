# 家庭园艺堆肥（garden-composting）

目标：**让有机物在可控条件下腐熟，产出稳定、无臭、不烧根的腐殖质**。
判断标准很朴素：温度曲线走过一遍、体积塌掉一半以上、闻起来是泥土味、
抓一把看不出原料形状——四条都到才算腐熟，「差不多烂了」不算。

三条不可妥协：

1. **先测含水率再动手**。堆体含水率应当在 50%–60%，也就是抓一把拧不出水、
   松手能成团、落地能散开。含水率不对，后面调碳氮比、加菌剂全是白费力气，
   因为微生物既泡死又渴死。凭手感猜是腐熟失败的主要来源。
2. **不混进新体系**。已经在用蚯蚓箱就别往里倒柑橘皮和洋葱皮，
   已经在做厌氧发酵桶就别中途开盖翻堆。要换堆肥方式就单独起一堆，
   不能夹在「这箱怎么不热」里偷偷改。
3. **腐熟自证**。温度记录 + 体积对比 + 气味与种子发芽测试必须都过关才算完成。
   没做发芽测试就把半成品埋进花盆，烧根之后追溯不出原因。

## 30 秒起步

在**院子或阳台的固定位置**开工。容器只买一次：带盖透气堆肥箱 1 个
（120L 起，底部离地），或自制木框 1m×1m×1m；蚯蚓箱另需托盘与椰糠垫料，
厌氧桶另需 EM 菌液与滤网。剪枝料要碎到 5cm 以内，所以还需要一把剪枝剪或碎枝机。

```bash
# 模式 A：救活已有的一箱——先测温测水再动
probe --pile backyard-01 --depth 40cm --log temp.csv
fix --pile backyard-01 --water 8L --brown 2bucket --turn 1

# 模式 B：从零起一堆——铺层 + 接种 + 首轮测温
build --volume 1m3 --cn 28:1 --layers 5 --starter compost-tea
schedule --turn day3,day7,day14,day28 --target-temp 55-65C
```

以上命令是本手册的记法，不是真能执行的脚本；把参数抄进你自己的记录表就行。
逐步工作流与交付说明模板见文末「参考指针」一节。

## 先判断是哪一种活

| 你面对的情况 | 走哪条 |
| --- | --- |
| 「这箱发臭 / 不升温 / 长白毛 / 招虫子」 | **模式 A：诊断与抢救**——已有堆体，先测温测水，五步流程见下 |
| 「我要从零开始堆 / 秋天落叶太多 / 想养蚯蚓」 | **模式 B：起新堆**——空容器，按配比路由表选材料与节奏 |

**救活已有堆体的五步**：①插温度计测堆心温度（40cm 深）；②抓料测含水率；
③闻气味定性（氨味＝氮过量，酸臭＝厌氧，土腥＝正常）；④按定性结果只调一个变量
（加水、加干料、或翻堆供氧）；⑤三天后复测温度，升温说明调对了，没升再动下一个变量。
一次只调一个变量，否则永远不知道是哪一步起了作用。

## 模式 B：材料配比路由表

一句话需求 → 堆法 → 碳氮比 → 首轮翻堆时间。没覆盖的组合查文末速查表第一节。

| 你要处理的东西 | 堆法 | 目标 C/N | 先准备的干料 |
| --- | --- | --- | --- |
| 每日厨余（菜叶果皮咖啡渣） | 好氧箱式 | 25:1–30:1 | 干落叶、碎纸板、锯末 |
| 秋季落叶成堆 | 露天围框 | 40:1（需补氮） | 无需干料，要补氮肥或鲜草 |
| 剪枝与粗枝 | 露天围框（碎到 5cm） | 35:1 | 鲜草屑、厨余作氮源 |
| 草坪修剪量 | 摊薄混入 | 15:1（氮过高） | 大量干料，厚度不超 5cm |
| 蚯蚓箱日常投喂 | 蚯蚓床 | 25:1 | 椰糠、撕碎报纸、蛋壳粉 |
| 咖啡渣为主的店面回收 | 好氧箱式 | 20:1（氮极高） | 木屑按 1:2 体积比掺入 |
| 蛋壳与骨粉 | 任意堆法辅料 | — | 洗净晒干碾碎，调节 pH |
| 冬季低温期起堆 | 保温箱式 | 28:1 | 泡沫箱或草垫包裹，体积不小于 1m³ |
| 只想做液体肥 | 堆肥茶厌氧浸泡 | — | 通气泵或每日搅拌，48 小时内用完 |
| 宠物粪便与肉类 | 高温厌氧深埋 | — | 家庭堆肥禁止，理由见「不要放」清单 |

```bash
build --volume <体积> --cn <碳氮比> --layers <层数> --moisture 55%
# 常用追加：
#   --inoculant <菌剂|老堆肥|堆肥茶>   接入活性微生物，起温快 2–3 天
#   --shred <5cm|10cm>                  碎料粒度，越细升温越快但越易板结
#   --cover <草垫|旧地毯|黑色塑料>       保温保湿，雨季要能排水
#   --no-worm                           明确不养蚯蚓（高温阶段本来也养不活）
```

**层铺法是新手最稳的路径**：一层干料（10cm）→ 一层湿料（5cm）→ 一层旧堆肥或园土
（2cm，当菌种）→ 重复到 1m 高，最上面必须盖干料封顶，这层盖料就是防臭防虫的关键。
起堆后第 3 天第一次测温，48 小时没升温就说明缺水或缺氮，别急着翻。

## 材料四件事（动手前定死）

1. **碳源（棕料）**：干落叶、碎纸板、报纸、锯末、稻草、玉米秆、松针。
   提供能量与孔隙，是让堆体透气的骨架。松针与橡木叶分解慢，单独堆或先切碎。
2. **氮源（绿料）**：鲜草屑、菜叶果皮、咖啡渣、豆渣、鲜剪枝、动物粪便（草食类）。
   提供蛋白质合成所需氮，是升温的燃料。氮过量的表现就是氨味与苍蝇。
3. **水**：每次加干料后都要补水，目标含水率 50%–60%。自来水最好晾晒一天散氯，
   雨水最佳。冬季用温水，冰水会把堆体直接降到微生物停摆的温度。
4. **空气**：好氧菌要氧。堆体中心温度超过 65℃ 说明供氧或含水出了问题，
   要么翻堆要么加粗料撑孔隙；温度长期停在 40℃ 以下则是氮不足或体积太小。

**不要放**：肉类、鱼骨、油脂、奶制品、熟食、猫狗粪便、生病植株、结籽杂草、
涂布纸（铜版纸与热敏小票）、经过防腐处理的木料、大量柑橘皮（蚯蚓箱）。
理由分别是招鼠招蝇、可能带寄生虫卵、可能带病原菌、可能带除草剂残留、
油墨与塑膜不参与分解、化学药剂会杀死菌群。

数值拿不准先查再猜：常见材料的 C/N 比是锯末 300–500、干落叶 40–80、稻草 60–80、
报纸 150–200、纸板 120–180、鲜草屑 12–20、咖啡渣 20、菜叶果皮 25、鸡粪 6–10、
牛粪 20、蚯蚓粪 12。混料时用「体积加权」算总 C/N，不要按重量算——
干料极轻，按重量算会严重低估碳源占比。

## 质量门（四项全过才算腐熟）

| 检查 | 做法 | 标准 |
| --- | --- | --- |
| 温度曲线 | 每日同一时间插温度计记 40cm 深处 | 经历过 55–65℃ 高温期 ≥ 3 天，随后回落到接近气温且不再回升 |
| 体积与颜色 | 起堆时插标尺拍照 | 体积塌掉 40%–60%，颜色深褐近黑，抓一把松散不粘手 |
| 气味 | 直接闻，必要时切开堆心 | 森林土腥味；氨味、酸臭、腐败味任一出现即不合格 |
| 发芽测试 | 堆肥与蛭石 1:1 混盆，播 10 粒小白菜或萝卜种 | 7 天发芽率 ≥ 80%，根白无褐变，对照盆同步 |

发芽测试是唯一能证明「不烧根」的手段，别省。氨味重说明氮没走完，
酸臭说明厌氧产生了有机酸，两者都会让种子发不出芽或幼苗猝倒。
翻堆后 24 小时内温度不回升，通常意味着可分解的碳源已经耗尽，这时可以停了。

**手工项（不能用温度计替代）**：手抓含水率、掰开大块看内部是否有白色菌丝、
过 1cm 筛把没烂的粗料挑回去下一堆。筛下物才是能直接拌土的成品。

## 常见问题诊断表

| 症状 | 最可能的原因 | 处置（一次只做一个） |
| --- | --- | --- |
| 氨水味刺鼻 | 氮过量，C/N 太低 | 加 2–3 倍体积干料（落叶/锯末），拌匀，48 小时后复闻 |
| 酸臭、黏成块 | 含水过高导致厌氧 | 翻堆摊开晾 2 小时，加粗料撑孔隙，之后少加水 |
| 一点不升温 | 体积太小 / 太干 / 氮不足 | 先测含水率；干则补水，湿则查体积，体积不足 0.5m³ 就并堆 |
| 升到 70℃ 以上 | 供氧或水分失衡，菌群走向放线菌 | 立即翻堆降温，避免有益菌被杀死与氮素挥发 |
| 表面长白毛 | 放线菌或木霉，通常无害 | 若伴随酸臭按厌氧处理；无异味则不用管 |
| 大量小飞虫（果蝇） | 湿料裸露在表面 | 每次投喂后盖 5cm 干料封顶，必要时套纱网 |
| 招蚂蚁 | 堆体过干 | 补水到 55%，蚂蚁会自行搬走 |
| 有蛆（黑水虻幼虫） | 蛋白类原料或过湿 | 挑出蛋白类原料；黑水虻本身是好分解者，可留 |
| 半年不腐熟 | 长期缺水缺氮、从未翻堆 | 重新配比 + 加水 + 加菌种，按首轮节奏翻三次 |
| 蚯蚓大批逃离 | 过热、过酸或含水失衡 | 移到阴凉处，加碳酸钙或蛋壳粉调 pH 到 6.5–7.5 |

## 翻堆节奏与时间预期

好氧箱式在 20–30℃ 环境下：第 3 天首翻（或测温后决定），第 7、14、28 天各翻一次；
6–8 周得到半成品，3 个月完成腐熟并过筛。夏季温度高可缩短到 4–6 周，
冬季低于 10℃ 时微生物近乎停工，堆体要保温，否则拖到第二年春天。

蚯蚓箱不翻堆，靠蚯蚓自己走：投喂集中在一个角落，等蚯蚓全部迁过去后
把另一侧的成品挖出来，周期约 8–12 周。蚯蚓箱温度控制在 15–25℃，
夏天放阴凉处，冬天搬进室内，pH 每周测一次。

厌氧桶（EM 发酵）密封 2–4 周，取出的发酵液稀释 500 倍当液肥，
固体残渣仍需埋土或入好氧堆完成二次腐熟，直接下地会烧根。
