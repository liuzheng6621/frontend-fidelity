# StyleKit 风格目录站实测蒸馏（stylekit.top/zh/styles）

> 样本：<https://www.stylekit.top/zh/styles>（2026-10 实测，1440 × 900 / 390 × 844 / devicePixelRatio 2）
> 另采一页详情：</zh/styles/neo-brutalist>
> 采集方式：headless Edge 直接可达（无 WAF），`scripts/probe-ref.mjs` + 自写探针。数值为 computed style 实测值。

## 一、它是什么气质

一句话：**一座把"风格"当商品陈列的美术馆——每张卡就是那件作品本身。**

四条可辨识特征：

1. **卡片即预览**。149 种风格，每张卡的预览区不是截图，而是用**该风格自己的 CSS 现场渲染的一套迷你组件**（背景 + 卡片 + 标题 + 副行 + 按钮）。Neo-Brutalist 那张卡里就真的有一个 `bg-[#ccff00]` 的底、一张 `border-4 border-black` 配 `shadow-[6px_6px_0_0_#000]` 的白卡、一个 `bg-[#ff006e]` 硬阴影按钮。**展品与展柜用同一套语言。**
2. **6px 四段色板条**。预览正下方一条 6px 高的色带，永远四段等分，取色顺序固定：**背景 / 前景 / 强调 / 辅色**（`#000/#fff/#ff006e/#ccff00`）。这是全站最省力也最有效的"风格身份证"。
3. **通体直角**。面包屑、卡片、输入框、chips、色板条全 `border-radius: 0`；圆角只留给"控件"（排序下拉 6px、图标按钮 50%）。像一本平版印刷的样本册。
4. **衬线标题 + 无衬线正文 + 等宽标签**。Playfair Display 写所有标题（36/45/500，-0.02em），Albert Sans 排正文，Fragment Mono 只做 hex、特征词、数字。

一句话可用性判据：**当你要陈列"一批彼此不同的东西"时，别截图，让每件东西自己渲染出来。**

## 二、令牌（实测）

### 2.1 chrome 五件套

| 语义 | 值 | 用在哪 |
| --- | --- | --- |
| 背景 | `#fafafa` | 全站底（**不是纯白**，是"纸"的颜色） |
| 前景 | `#0a0a0a` | 文字、hover 边框、chips 选中底 |
| 次级文字 | `#6b7280` | 说明段、计数、标签、未选中 chip 字 |
| 分隔 | `#e5e5e5` | 全站唯一分隔手段：1px 边框 / border-b / chips 边 |
| 强调 | `#e63946` | 绯红，**全站唯一饱和色**，只用于 hover 时的标题与少量小标记 |

页脚另用一档深色 `oklch(0.141 0.005 285.823)`（≈ zinc-950），`border-top` 一档 zinc-800。

### 2.2 圆角分工（这是它最讲究的一处）

| 档 | 值 | 归属 |
| --- | --- | --- |
| 直角 | `0` | 卡片、预览、色板条、输入框、chips、统计格、整行链接 |
| 控件 | `6px`（`rounded-md`） | 排序下拉、header 的搜索按钮 |
| 圆 | `50%` | 24×24 图标按钮、头像/星标等 |

> 度量时 `rounded-full` 会被算成 `3.35544e+07px`（= 2^25），别当成"异常值"，那是 Tailwind 的 `calc(infinity * 1px)` 取整。

### 2.3 阴影

**chrome 层零阴影**——全站分隔只靠 1px `#e5e5e5`。出现的那条硬阴影（`6px 6px 0 0 #000`）在 Neo-Brutalist 卡片**内部**，属于展品，不属于展柜。这是"目录站"该有的克制：**陈列区的层次由版式给，不由阴影给。**

### 2.4 字重与字距

- 字重只有 **400 / 500**（卡片内部展品可以到 900，那是展品自己的事）。
- 字距三档，各有归属：
  - 正文 normal；
  - eyebrow（`设计风格集合`）**0.18em**（11px → 1.98px）；
  - 全大写小标签（`HIGH-CONTRAST`）**0.16em**；
  - 场景 chips 额外 **0.3px**（中文小字要一点点呼吸）。

### 3.2 中文标题的真实渲染（重要，别照抄错）

Playfair Display **没有中文字形**。所以 `网页与 UI 设计风格` 这行中文实际落到**系统 serif 回退**：Windows 上是宋体/SimSun 系列，macOS 上是 Songti SC，Android 上常常是 Noto Serif CJK——**三个平台三种骨架**，而它没有在字体栈里补任何中文衬线。

复现时要点名补一行：

```css
font-family: "Playfair Display", "Songti SC", "Source Han Serif SC", "Noto Serif CJK SC", serif;
```

反过来说，这条也是"**用拉丁衬线做中文标题**"这种玩法的入场券：**你必须为中文单独指定一个衬线，否则交付到客户 Windows 上会变宋体。**

### 3.3 三件套分工

| 角色 | 字体 | 只做什么 |
| --- | --- | --- |
| 标题 | Playfair Display（variable，500） | H1/H2/H3、卡片内展品标题 |
| 正文 | Albert Sans（variable，400/500） | 段落、按钮、导航、计数 |
| 等宽 | Fragment Mono | hex、特征词、纯数字 |

三件套 + 直角 + 单一强调色 = 这套"样本册"气质的全部配方。**它没有用任何图片做装饰**（全站 `<img>` 极少），视觉密度全靠三个字体和一堆 1px 线。
## 四、版式节奏（1440 × 900 实测）

| 段 | 高度 / 尺寸 | 细节 |
| --- | --- | --- |
| 促销条 | 40px | 黑底白字，「v0.18.1 — 量化线场上线 / 体验新风格」+ 右侧关闭；中文里夹英文版本号，用 `·` 与空格分开 |
| header | **81px** | `border-bottom: 1px #e5e5e5`，static（不吸顶）；左边 wordmark、右边一排 10px 级图标钮 |
| 面包屑 | 24px | `Home / Styles`，14px muted，斜杠两侧留空格 |
| 页头 | ~210px | eyebrow 11px → H1 36px → 说明段；右侧嵌三格统计 |
| 三格统计 | 每格 **117 × 59** | `border-right` 分格，`dt` 10px 全大写字距 0.16em，`dd` 18–20px `tabular-nums` + `leading-none` |
| 说明区 | 两栏 | 左 `3/5` 文本（H2 30 + 两段 16/24），右 `2/5` 三个**整行箭头链接**（白底 1px 边，整行可点） |
| 筛选区 | 搜索 448×40 → 提示 12 → 场景 chips **38 高**（11 个）→ 类型 chips **32 高** + 收藏钮 → 标签下拉 | 三层筛选，逐层降级：场景是"内容分类"，类型是"资料形态"，标签是"细节" |
| 结果行 | 24px | 左 `已显示 24 / 149 个结果`；右排序下拉 **144 × 44** |
| 图墙 | 3 列，`gap 32`，容器 **1184** | 卡片 **373 × 466**：预览 `4:3` = 371×278 + 色板 6 + 文本区 180 |
| 页脚 | **783px** 深色 | 4 组栏目 + 订阅框 + 底行备案；`border-top` zinc-800 |

三条要点：

1. **一屏三种节奏块，只用一条线分界**——居中页头 / 左文右链 / 满宽图墙，三段之间没有任何底色差，全靠 1px `#e5e5e5`。这是"样本册"的版式逻辑：**纸只有一种，栏目靠栏线**。
2. **卡片高度被预览比例锁死**：预览永远 `4:3`，文本区永远 180px（标题一行 + 描述两行 + 标签一行）。**整齐来自"每张卡高度公式相同"，不来自"每张卡内容相同"**——所以它敢用直角、敢零阴影。
3. **筛选逐层降级**：11 个场景 chips（38 高，占一整行）→ 3 个类型 chips（32 高，带图标）→ 1 个标签下拉。越细的筛选项，控件越小、越靠后。

### 4.1 移动端（390 × 844）

- header 压到 **65px**，导航收进汉堡；场景/类型 chips 全部折进一个整行的 **「⚙ 筛选」按钮**（不再横排 11 个，避免横滚）。
- 图墙 **2 列、gap 12**，卡片 **173 × 300**；卡片里的英文名 `hidden sm:inline` 直接隐藏——**只留中文名，一行放得下**。
- **底部固定 tab bar**（首页 / 风格 / 模板 / 搜索，图标 24 + 文字 12），高约 56；右下浮动"回到顶部"。
- `scrollWidth === innerWidth === 390`，无横滚。**这一条是"移动端做没做"的唯一硬指标。**

## 五、组件配方

### 5.1 风格卡（全站核心，六层）

```
div.group.relative.border.border-border          ← 无圆角、1px 边、白底
├ a.absolute.inset-0.z-10                        ← 整卡可点（覆盖层）
├ div.relative.overflow-hidden.aspect-[4/3]      ← 预览：固定比例，超出裁掉
│   └ div.style-cover-preview                    ← 该风格自己的迷你 DOM（真 CSS）
├ div.h-1.5.flex                                 ← 色板条：6px，4 段 flex-1
├ div.p-3.sm:p-4.md:p-5                         ← 文本区：pad 20
│   ├ h3.text-base.truncate（16px 中文名）
│   ├ span.text-sm.text-muted.hidden.sm:inline（14px 英文名）
│   ├ p.text-sm.leading-relaxed.line-clamp-2（14/1.625，两行封顶）
│   ├ span（场景标签：10px + 1px 边，高 21）
│   └ span（特征标签：10px + 全大写 + 字距 0.16em + zinc-100 底，高 19）
└ button ×2（24×24 rounded-full，右上角，白 80% 底：复制提示词 / 收藏）
```

三个必须记住的数字：**预览 4:3、色板 6px、文本区 180px**。三个数字定死，149 张卡不用管内容长短都对齐。

**hover 只有两笔**（实测）：

| 元素 | 默认 | hover |
| --- | --- | --- |
| 卡片边框 | `1px #e5e5e5` | `1px #0a0a0a`（转黑） |
| 卡片标题 | `#0a0a0a` | `#e63946`（转绯红） |

没有位移、没有阴影、没有缩放。**两笔就够**——因为卡片里已经有一整幅彩色预览，任何额外动效都是噪声。

### 5.2 场景 chips（38 高）

`padding: 10px 16px`、12px 字、字距 0.3px、**radius 0**；选中＝黑底 `#0a0a0a` + `#fafafa` 字，未选＝透明底 + 1px `#e5e5e5` 边 + `#6b7280` 字。11 个正好一行。

### 5.3 类型 chips（32 高，带图标）

`padding: 6px 12px`、14px 字、gap 6、radius 0。**比场景 chips 小一号**：同一屏里"更细的筛选"必须看起来更轻。

### 5.4 搜索框

448 × 40、`bg #fafafa`、1px `#e5e5e5`、**radius 0**、`padding-left: 40px`（给放大镜）、14px 字。下方一行 12px 提示：`提示: 按 / 可快速聚焦搜索，按 Esc 可清空。`——**把快捷键写出来，而不是藏进 tooltip**。

### 5.5 排序下拉

144 × 44、`bg #fafafa`、1px 边、**radius 6px**。这是全站唯一一处非 0 圆角：它是个"原生表单控件"，需要一点点圆来脱离方阵。

### 5.6 整行箭头链接

白底、1px `#e5e5e5` 边、`padding: 16px 20px`、14–16px 字、右端一个 `→`。三行叠起来就是一列"下一步去哪"。**比自己发明卡片便宜十倍，比裸文本链接清楚十倍。**

### 5.7 三格统计

`border-right` 分格 + `padding: 10px 12px` + 居中；`dt` 10px 全大写 muted（`全部` / `视觉风格` / `布局模式`），`dd` 18–20px `tabular-nums`。**数字用 `tabular-nums`，否则换数字时宽度跳动。**

### 5.8 悬浮图标按钮（24 × 24）

`rounded-full`、白 80% 底、`zinc-100` hover 底、图标 14–16。放在预览右上角，**默认就是可见的**（不靠 hover 才出现——移动端没有 hover）。

### 5.9 移动端三件套

筛选折叠按钮（整行、带竖直滑杆图标）→ 2 列图墙（gap 12）→ 底部 tab bar（4 项 + 当前项实心）。**PC 版直接把 11 个 chips 横排塞进 390 是最常见的翻车点。**
## 六、详情页：同一站的第二套版式（/zh/styles/<slug>）

列表页是"陈列"，详情页是"说明书"。两页共用同一套字体与直角，但节奏完全不同——**这一点比任何单页都值得学：一个内容站要有"列表版式"和"详情版式"两种，且它们必须同族不同形。**

实测（`/zh/styles/neo-brutalist`，`docH` 12,005）：

| 段 | 实测 | 说明 |
| --- | --- | --- |
| H1 | **60 / 60 / 500 Playfair** | 行高 = 字号（1.0），大标题靠衬线自身撑开，不额外加行距 |
| 区块 H2 | **30 / 36 / 500** | 「先复制硬性提示词，需要时再看设计规范」「评分与反馈」「组件预览」「新野兽派的鼠标交互」 |
| 色板 swatch | 每格 **83 宽**，色块 + 12px `Fragment Mono` hex | 文本是 `Primary #000000` / `Secondary #ffffff` / `#ff006e`——**角色名 + 值**，不是只给一个色块 |
| 提示词块 | `pre` **1150 宽**、`bg #fafafa`、pad 24、`ui-monospace` **14/23.8（1.7）** | 内容是结构化 YAML：`STYLEKIT_STYLE_REFERENCE` / `style_name` / `style_slug` / `# Hard Prompt` / `## 什么时候用` |
| 按钮组 | 「返回目录」「复制硬性提示词」「说明书 · 质检标准 Design Spec」「探索 · 改版方向 Creative Brief」「项目实施简报（可选）」「复制」「下载」 | **同一页给三种"深度"的作业单**：硬性规则 / 说明书 / 创意简报 |
| 组件预览 | 按「按钮 / 卡片 / 输入框 / 导航 / Hero」分类，每类带「查看代码」「复制代码」 | 预览 + 代码开关，不逼你复制整页 |

五个可迁移的招：

1. **色板给"角色名 + 值"**，不给一串色块。`Primary #000000` 比 `#000000` 有用一个数量级。
2. **大标题行高打到 1.0**（60/60）。中文 60px 配 1.0 行高只适合单行标题——多行会挤；这家标题都是短的，所以成立。
3. **把"给 AI 的提示词"当成一等公民内容**，用等宽 + 浅底 + 1.7 行高的 `pre` 呈现，并给"复制"按钮。2026 年的内容站，这种块比"下载 PDF"更常用。
4. **同一页给三种深度的产出**（硬性规则 / 设计说明书 / 创意简报）。用户要哪一层自取，减少"你到底想让我怎么用"的来回。
5. **组件预览区带"查看代码 / 复制代码"**，预览与源码在同一个位置切换，不跳页。

反面：`pre` 块 1150 宽、16991 高（一整屏 12,005 里它占 17,000 像素？——实测该 `pre` 高度为 16,991，说明**提示词块没有折叠**，页面前 1/3 之后就是一条两万像素的长文本）。**长提示词必须折叠或分块 + 目录跳转**，否则详情页等于一个纯文本文件。

## 七、七处没做好（如实记录）

1. **深色模式是半成品**：header 有 `切换到深色模式` 按钮（aria-label 齐全），但点击后 `html.class` 仍是 `light`、`--background` 仍是 `#fafafa`——**未取到任何深色令牌**。有开关没效果，比没有开关更伤。
2. **预览区是真实 DOM，读屏会念展品**：每张卡的迷你预览里有 `ACTION` / `READ MORE` / `Button` / `Card` 等真实文本节点，24 张卡 = 一百多个无意义可读元素。**预览必须 `aria-hidden="true"`（或 `inert`）**，可点区域交给那层 `a.absolute.inset-0`。
3. **预览里的字太小且被裁断**：桌面 371 宽里放 10–12px 文字尚可，移动端 173 宽时正文变 6–8px 且 `overflow: hidden` 直接切掉半行（`BRUTAL`、`Editorial`、`Neumorphism` 三张都能看到截断）。预览是"示意"，**应该按容器宽度缩放整个迷你 DOM（`transform: scale()` 或容器查询），而不是让小字被裁**。
4. **无限滚动没有兜底**：`已显示 24 / 149`，滚动追加 24，**没有"加载更多"按钮、没有分页、URL 也不记位置**。键盘用户与读屏用户很难触发下一批；刷新即回到第 1 张。至少补一个"加载更多"按钮作为出口。
5. **图标按钮 24×24**：复制与收藏都低于 44×44 的触控下限，移动端也没变大（移动端预览更窄，两个圆钮反而更挤）。
6. **圆角体系被一个下拉破功**：全站 0 圆角，只有排序下拉 6px。要么"控件统一 6"，要么"全 0"，现在这一处像是随手 `rounded-md` 留下的。
7. **上下两条固定带挤压首屏**：促销条 40（可关）+ 移动端底部 tab ~56，390×844 的首屏有效高度只剩 ~700，且促销条关闭后不记忆（刷新又出现）。

## 八、能搬什么 / 不能搬什么

| 能直接搬 | 为什么 |
| --- | --- |
| **卡片即预览**（真 CSS 渲染，不截图） | 一批"彼此不同"的东西陈列时，截图会失真、会过期、会糊；活渲染永远准 |
| **6px 四段色板条** | 一行 CSS，立刻给每张卡一个"身份证"；四段固定语义（底/字/强调/辅） |
| **直角 chrome + 控件圆角分工** | 陈列区 0、控件 4–6、圆形只给图标钮；一条规则管住全站 |
| **hover 两笔**（边框转黑 + 标题转强调色） | 卡片内部已经很花，动效越少越好；两笔已足够"这是可点的" |
| **eyebrow 11px / 0.18em** | 中文页头想要"编辑感"最便宜的一招 |
| **整行箭头链接** | 替代"三个功能卡片"，成本 1/10，可读性更高 |
| **三格统计 + `tabular-nums`** | 页头右侧填充空白的标准答案 |
| **移动端：筛选折成按钮 + 底部 tab bar** | 11 个 chips 在 390 宽横排必翻车 |

| 别搬 | 为什么 |
| --- | --- |
| 无限滚动无出口 | 可访问性与可回溯性双输；至少给"加载更多" |
| 预览区 10px 小字 | 移动端直接不可读；用缩放而不是缩字号 |
| 24×24 触控目标 | 低于 44 下限 |
| 半成品深色模式 | 有开关无效果最伤信任 |
| 未折叠的两万像素提示词块 | 等于把详情页做成 txt |

**混合口径（和本 skill 其它文件对齐）**：

- 直角 `0` 只适合"内容陈列区"；**管理后台不要用 0 圆角**——输入框、下拉、按钮在 0 圆角下焦点环是尖角，视觉上像 2008 年的表单。后台请用 `--r-control: 4~6px`。
- 这套"纸"色 `#fafafa` + `#e5e5e5` 线 + `#e63946` 一点红，可以直接替换成任意一档"低饱和底 + 单一强调"，但**强调色只能出现在 hover / 选中 / 极小标记**上；一旦铺面积，样本册就变促销页。
## 九、复现清单（照着做，一小时能给出一版）

1. **定五件套**：底 `#fafafa`、字 `#0a0a0a`、次 `#6b7280`、线 `#e5e5e5`、强调一个（这家的绯红 `#e63946`）。**只五个值，不许再加。**
2. **定圆角三档**：陈列 `0` / 控件 `6` / 图标 `50%`。写进 CSS 变量 `--r-frame / --r-control / --r-round`。
3. **定字体三件套**：标题衬线（Playfair / 思源宋体）、正文无衬线（Albert Sans / 思源黑体）、等宽（Fragment Mono / JetBrains Mono）；**中文衬线必须显式写进栈**。
4. **页头**：promo 40（可关）+ header 81（`border-bottom: 1px`、不吸顶）。header 里放 wordmark + 一排图标按钮（14–18px）+ 一个登录。
5. **页头块**：eyebrow（11px / 0.18em / muted）→ H1（36px 衬线 / -0.02em）→ 一句说明（16/24）→ 右侧三格统计（117×59，`tabular-nums`）。
6. **说明区两栏**：左 3/5 文本，右 2/5 三个整行箭头链接。
7. **筛选三层**：搜索（448×40、radius 0、左内边距 40）+ 场景 chips（38 高、11 个）+ 类型 chips（32 高、带图标）+ 结果行（左"已显示 N / M"、右排序 144×44 radius 6）。
8. **图墙**：3 列、gap 32、容器 1184；卡片 = `4:3` 预览 + **6px 四段色板** + 180px 文本区（标题 16 truncate / 英文名 14 muted / 描述 14 line-clamp-2 / 两个 10px 标签）。
9. **预览要活**：每张卡用真 CSS 渲染迷你组件（底 + 卡 + 标题 + 按钮），外层 `overflow: hidden` + `aspect-ratio: 4/3`，整体按容器宽度缩放；**加 `aria-hidden="true"`**。
10. **hover 两笔**（边框转 `#0a0a0a`、标题转强调色）+ **焦点环用 2px outline offset 2**（这家漏了，你必须补，直角卡片尤其需要）。
11. **移动端**：2 列 + gap 12；筛选折成整行按钮；底部 tab bar 4 项；`scrollWidth === innerWidth`。
12. **验收**：跑 `scripts/audit.mjs` 看对比度（`#6b7280` on `#fafafa` = 4.6:1，刚好过；再浅就不合格）与触控目标（图标按钮提到 32–44）。

三个容易踩的点：

1. **全站 2880×19508 的长截图截到一半就全白**——因为它无限滚动懒挂载，`screenshot.mjs` 的整页模式拿不到后续卡片。要看下半页就 `window.scrollTo` 分段截，或直接数 `已显示 N / M` 那行。

3. **深色模式点了没反应**——不要为了凑一个"深色令牌表"去臆造，如实写"未取到"。
