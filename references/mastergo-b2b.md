# MasterGo（莫高设计）：工具类产品站该学的三层东西

> 采样：`https://mastergo.com/` 官网 + `/community` 资源社区（2026-11，1440×900）。
> 素材：官网三张 **1800×1536** 官方产品图（`images/home/{design2,prototype2,develop2}.png`）、社区 24 张资源卡的真实元数据。
> 用途：**B 端工具界面**（工作区三栏、属性面板、代码面板）怎么排；B 端资源库里什么被真用。
> 边界：资源实例本体在 `<canvas>` 里，未登录只能拿到封面与元数据；下面所有结论要么量自公开像素，要么统计自公开卡片。

## 一、先说清楚"学什么"——三层，价值递增

| 层 | 能拿到的 | 值不值得学 |
|---|---|---|
| **外壳**（营销页） | 渐变、按钮三档、logo 墙、色带 | 能抄，但廉价；任何 SaaS 都能长这样 |
| **工具界面实例**（官方产品图 1800×1536） | 三栏工作区的真实尺寸、属性面板的字段语言、代码面板的语法色 | **最值钱**：这是"B 端工具"的通用骨架 |
| **社区实例清单**（24 张资源卡） | 谁被反复抄、什么被真用（赞 vs 使用数） | 值钱：能反推"应该交付什么颗粒度" |

只有第一层是"表面"。这份文档的 80% 在第二、三层。

## 二、工具界面实例解剖（量自 1800×1536 官方图）

官方给了同一工作区的两种模式：**设计模式**（`design2.png`）与**研发模式**（`develop2.png`），
`develop2.png` 还是**左右对照**——左边设计模式、右边研发模式，同一张卡片在两侧同时出现。这是一个非常好的"同源对照"样本。

### 2.1 三栏工作区的骨架

| 区 | 宽（相对 1800 图） | 内容 | 底色 |
|---|---|---|---|
| 顶栏 | 56 | 文件标识（圆角 6 图标 + 文件名 + `⌄`）、右侧协作头像组 + 主按钮 | 白 / `#1E1E1E` |
| 左栏 | **300** | Tabs（图层 / 资源）+ 页面树 + 底部搜索 | 白 / `#252525` |
| 画布 | 自适应 | 深灰底上浮白色画板；选中元素蓝色 1px + 尺寸标签 | `#F2F3F5` / `#1E1E1E` |
| 右栏 | **300** | 属性 / 检查面板（分组纵向堆叠） | 白 / `#1E1E1E` |

**左右栏同宽（300）**：这是工具类产品的隐含约定——两侧是"元数据"，中间才是"内容"，两侧宽度对等才不会让画布偏。

### 2.2 左栏：页面树

- 顶部 Tabs 两个词（「图层」「资源」），选中项下方 2px 短下划线；
- 「页面」小节：标题 12/600 + 右侧四个图标按钮（搜索 / 过滤 / 新建 / 更多），间距 4；
- 树条目：**13px**，行高 28，缩进 12；分组小标（`概览` / `基础组件（通用）` / `导航` / `输入`）用 **12px + 两侧短横线**（`--------- 概览 ---------`）当分隔，比加粗更省空间；
- 条目右侧的**彩色状态点 6px**（绿 / 黄 / 紫）表示"已同步 / 待更新 / 变体"，颜色语义靠图例维持，不靠文字；
- 底部单独一块「搜索图层」+ 最近引用列表（灰底 `#F7F7F8`、圆角 8、贴底）。

### 2.3 右栏：属性 / 检查面板的字段语言（**这一节最值得直接搬**）

研发模式右侧从上到下：

```
容器     ← 分组标题：12 / 600 / #B8B8B8（深色 #8A8A8A），行高 40，右侧折叠箭头
代码     ← 组内是"盒子模型图 + CSS 下拉 + 复制"
布局     ← 组内是键值代码行
样式
颜色
资源
导出
```

**键值行的排法**（几乎每个 B 端属性面板都能用）：

```css
.insp-group { border-top: 1px solid var(--line); }        /* 1px #2A2A2A，不是卡片间隔 */
.insp-group__title {
  display: flex; align-items: center; justify-content: space-between;
  height: 40px; padding: 0 12px;
  font: 600 12px/1 var(--font-sans); color: #8A8A8A;
}
.insp-row {
  display: flex; align-items: center; gap: 8px;
  min-height: 24px; padding: 2px 12px;
  font: 400 12px/1.6 var(--font-mono);                     /* 代码面板用等宽 */
}
.insp-row__key  { color: #7A7A7A; }
.insp-row__val  { color: #FFFFFF; }
.insp-row__num  { color: #7FB1FF; }                         /* 数值统一蓝，和属性名区分 */
```

三条判断：

1. **分组标题比内容还安静**（12/600/灰），因为用户永远在找"值"，不是在读"标题"；
2. **键与值不同色，数值再单独一色**——三层色阶让 12px 的等宽字在深色底上依然可分；
3. **分组之间只用 1px 线**，不用卡片盒子。深色面板里一旦加圆角卡片，视觉会碎成一片。

### 2.4 盒子模型图：数值直接标在边上

`代码` 组里不是纯文本，而是**嵌套矩形图**，每个边标着数字（`12` / `Padding 16` / `16` `268 × 277` `16` / `20` / `12`），
下方「CSS ⌄」切换语言、右侧复制。这是"一眼看懂间距"的最高效形式——比四行 `padding: 16px 16px 20px 16px` 直观。

复现要点：外框（margin 区）虚线、内框（padding 区）实线、中心写着 `W × H`，四个边各一个数字标签（10px 等宽）。

### 2.5 代码面板的语法配色（深色 `#1E1E1E`）

| 角色 | 色 |
|---|---|
| 属性名 | `#7A7A7A` |
| 冒号 / 分号 | `#555` |
| 值（字符串 / 单位） | `#FFFFFF` |
| 数值 | `#7FB1FF` |
| 选中行高亮 | `rgb(255 255 255 / .06)` + 左侧 2px 蓝条 |

配色逻辑：**只有"数字"是彩色的**。代码面板里最常被改的是数值，所以只给数值上色，其余全部灰白。

### 2.6 自动布局面板（`design2.png`，浅色）

- 面板：白底、圆角 16、阴影 `0 12px 32px rgb(0 0 0 / .12)`、内边距 16；
- 标题行：「自动布局」16/600 + 右侧 `?` + 右上 `—` `⋯`；
- 第一行**三段式图标按钮组**（水平 / 垂直 / 换行）：高 44、圆角 8、浅灰 `#F5F6F8`、选中态白底 + 1px 灰边；
- 第二行：`间距 20` 输入 + 右侧**九宫格对齐**（3×3 点阵，当前对齐方式用一个 44×44 的纯蓝方块标出）；
- 第三行：**内边距四格** `16 / 20 / 16 / 16`（左上右下顺序），每格 44 高、浅灰底、左侧小图标（上/右/下/左）；
- 数值字号 **20/600**，单位不带 `px`（面板语境里省略）。

判断：**属性面板里所有可点区域都不小于 44×44**，即使它看起来只是一行 12px 的字——这是工具类产品的硬标准，因为高频、精确点击。

### 2.7 从实例提炼的 8 条规则（可直接落到生成器）

1. 工作区左右栏**同宽 300**，画布才有中心感；
2. 面板**分组标题 12/600/灰**，值 12/等宽，数值单独一色；
3. 分组间**只给 1px 线**，不给卡片；
4. 数值可复制（每行 hover 出现复制钮），因为用户最终要把它交给代码；
5. **盒子模型图 > 四行 padding**；
6. 属性面板所有命中区 **≥44×44**，数值 20/600；
7. 树条目 **28 行高 + 12 缩进 + 6px 状态点**，状态靠色点不靠文字；
8. 深色面板不要把白底面板的"卡片 + 阴影"直接搬过去，会碎。

### 3.3 三条结论

1. **使用数最高的不是大厂组件库，是一份个人的"整页 B 端系统界面"（98.2k）**。组件库人人都有源文件，整页骨架才是能直接拿去抄的东西。
2. **中文 B 端生态被 Ant Design 统治**：24 张里 5 张是 Ant Design 系列，加上 TDesign / Arco / Element Plus，大厂体系占 11/24。
3. **"B 端"在这里是独立品类**：标签与分类里 `B端设计` 与 `界面设计` 并列，且 B 端专题下的图版密度明显低于移动端——说明 B 端资源稀缺。

### 3.4 对技能的启示（这条直接改了 `scaffold.mjs` 的取向）

交付物应该是**整页骨架**（一个后台列表页 / 一个数据看板 / 一个目录页），而不是"组件清单"。
组件清单谁都有，整页才是别人真正会复制走的东西。

## 五、能搬 / 别搬

| 能搬 | 别搬 |
|---|---|
| 三栏工作区（左右同宽 300） | 首屏 `position: fixed` 渐变放在移动端（iOS 上会抖，且吃滚动性能） |
| 属性面板的分组标题 + 键值行 + 数值色 | 11,154px / 12 屏的营销长页（移动端涨到 13,449px） |

| 代码面板"只有数字上色" | 区块标题行高 1.8（36/64.8）——中文超过 12 字就散 |
| 状态点 6px 代替文字状态 | logo 墙挤在一屏且 logo 大小不一（最高 40、最矮 20） |
| 面板内命中区 ≥44×44 | 促销条常年占 60px 顶在品牌叙事上面 |
| 整页骨架（社区验证：整页 > 组件清单） | 把深色面板的"卡片 + 阴影"直接搬到深色底上 |

## 六、复现清单：一个 B 端工具界面（10 步）

1. 布局：`grid-template-columns: 300px minmax(0,1fr) 300px`（左右同宽）、顶栏 56；
2. 顶栏：左（品牌圆角图标 + 文件名 + `⌄`）、右（头像组 + 主按钮）；
3. 左栏：Tabs（2 项，选中 2px 下划线）→ 页面树（行高 28、缩进 12、状态点 6px）；
4. 树的分组用「`---------- 标题 ----------`」样式（12px + 两侧短线），不要加粗大标题；
5. 画布底色 `#F2F3F5`（浅）/ `#1E1E1E`（深），内容卡白底圆角 16；
6. 右栏：6–7 个分组，每组「标题 40 高 + 内容」，组间 1px 线；
7. 分组内容优先给**代码行**（等宽 12）与**数值标签**，不要给大段说明；
8. 颜色 / 尺寸这类"可复制值"，每行 hover 出复制钮；
9. 深色面板配色：底 `#1E1E1E`、属性 `#7A7A7A`、值 `#FFF`、数值 `#7FB1FF`、分割 `#2A2A2A`；
10. 所有可点区域 ≥44×44，数值字号 20/600（属性面板）/ 12（代码行）。

## 八、重采方法（三个坑）

1. **资源实例本体在 `<canvas>` 里**，未登录拿到的详情页预览区是空的——只能拿到封面图与元数据（标题/作者/赞/使用/标签/更新时间）。
2. 社区首页会弹登录框（`欢迎回来`），它 3 秒后出现并遮住卡片；截图前要按 `Escape` 并把 `[class*=modal]`/`[class*=mask]` 里尺寸 >300×200 的节点移除。
3. 官网的渐变换在 `header::after` 上，`getComputedStyle` 查任何"有背景的元素"都会扑空——要遍历 `document.styleSheets[].cssRules` 里的 `::after` 规则。
