> 用途：`SKILL.md` 里凡是给出「字号 / 行高 / 圆角 / 间距 / 控件高度」的地方，数值都来自这里。
> 争议时以本文件为准；要扩样本就重跑 `scripts/probe-ref.mjs`。

## 一、样本与方法

采集时间 2026-10（A/B 组）、2026-02（Wegic、即时设计）。方法：无头 Chromium 1440×900 打开目标站，等 3–4s（字体与骨架稳定），
读取**实际计算样式**（`getComputedStyle`）：按字符数加权统计字体与颜色、统计字号分布、
取 `h1/h2/p/th/td/label/button/input` 首个实例的字号·行高比·字重、统计圆角与 gap 频次、
量测侧栏/表头/表格行高/控件高度、读取 CSS 变量命名。原始 JSON 未随包分发，重跑即可再生。

**采集成功 14 个站**（A 组 11 营销/产品站，B 组 3 后台），另有 1 个失败不计入。

## 二、跨站统计（11 个营销/产品站）

- 主题：**浅色 7 / 深色 3 / 黑白交替 1**（Wegic）。浅色仍是企业站默认，深色是差异化选择而非标配；
  黑白交替是产品站的做法（黑段叙事、白段放证据），对后台没有参考价值。
- 正文字号：均值 **15.0px**（10,12,12,13,14,15,15,16,18,20,20）；正文行高比均值 **1.445**（1.15–1.60）。
- H1：均值 **78.9px**（40–140），行高比 **0.80–1.51** ——大标题压到小于 1 的行高是普遍做法，但也有 1.5 的（即时设计 40/1.51）。
- **H1 / 正文 字号比：3.1 – 8.8 倍**（营销站语境；后台绝不能照搬，见第四节）。
- 主字体：Manrope×2、Inter×2、Geist、Outfit、DM Sans、Season Sans、Ivar Text、IBM Plex Mono ——
  多数是无衬线/几何/新怪诞，**10 站里 9 站自带 webfont**（系统栈只作 fallback）。
  唯一的反例是**即时设计：`document.fonts.size = 0`，一份 @font-face 都没有**，全站系统栈，
  中文渲染完全交给 PingFang/微软雅黑。它不是偷懒——中文 webfont 动辄几 MB，工具站把首屏速度排在品牌字前面，
  这是**中文站才成立的取舍**，英文站照抄会失去个性。
- **第二字体是等宽（mono）的有 5/11**：Suisse Intl Mono、Geist Mono、IBM Plex Mono、TheGoodMonolith、Berkeley Mono。
  用途统一：编号、标签、元信息、版本号、时间戳。
  另有一派**第二字体用手写/衬线做「批注层」**：Wegic 的 Damion（4 处 eyebrow）、banham 的 Ivar Headline。
- 间距频次：16px(7) ≈ 8px(7) > 4px(4) ≈ 12px(4) > 20·6·24(各 2–3)。
  派生值 `6.4px / 7.47px / 11.2px` 出现在两站——说明间距来自**缩放系数**而非手写像素。
  Wegic 是最极端的一站：gap 4px 出现 38 次、16px 16 次、12px 10 次，**基数就是 4**。
  即时设计给出另一种「缩放」：**根字号 13px + em**，于是所有尺寸都变成非整数
  （22.2857 / 30.797 / 44.564），节奏是「大块上下各 130」而不是 4 的倍数。
  **学它的节奏，别学它的小数**——按 13 的倍数落盘会得到一堆没法标注的值。
- 圆角频次：50%(6，用于头像/圆形)→ 2px(4) → 24px(4) → 4px(3) ≈ 9999px(3) ≈ 999px(3) ≈ 50px(3)。
  **双轨制**：小控件 2–8px 方一点，同时存在胶囊 999/9999px 用于标签与 CTA。
  Wegic 给出更干净的分工：**12px(48 次) 单一主力 → 20px 暗卡 → 9999 标签 → 58 大媒体框**。
  即时设计是反例：**七档圆角（7.43 / 8 / 10 / 11.14 / 12 / 13 / 14.86 / 20 / 22.29 / 1000）没有递进关系**，
  同样来自 em 缩放。圆角必须能一眼看出内外层级，否则只剩记忆成本。
- 容器宽：1440 视口下主内容 **1250–1450px**，正文段落栏宽收在 600–800px。
  Wegic 用标准 `max-w-7xl` = 1280 + 32 水平内边距，是这一档里最省事的写法。
  即时设计 1277（`max-width: 1280` + 卡片贴满），卡片级圆角 22 直接把容器吃掉——适合「卡片即页面」的产品站。
- 图片：`loading="lazy"` 近乎全量（如 165 张里 164 张），不是可选优化。
- 动画数量 0–34，**中位数 1**：动效克制的那几站并不显得低级。
  Wegic 桌面 8 个、移动 0 个——**移动端做减法才是及格线**。
  即时设计只有 3 个 @keyframes（breath / autoScroll / flow），其余全靠 GSAP 滚动编排；
  它的 hero 用「三屏视频轮播」讲设计→原型→开发，**动画承载信息而不是装饰**，这类叙事也不能上后台。
- **阴影用法分两派**：linear 一派「几乎不用阴影，靠边框」（20 边框 / 2 阴影）；
  Wegic 一派「不用边框，靠发丝圈 + 内阴影」（`0 0 1px 1px` 用了 24 次）。两派都好，
  混着用（每张卡又有边框又有阴影）才是廉价感的来源。
  即时设计是第三派：**不用边框，靠「负扩散阴影 + `0 0 0 1px` 发丝环」**
  （`0 16px 16px -16px` 用 28 次），阴影负扩散不外扩，卡片像贴在底板上。
  戏剧性大阴影（`0 50px 100px -20px`）只给浮起来的设备截图，20 处——**两套分职，才敢用大阴影**。

## 三、可以直接抄的招式（带出处）

1. **等宽字体做「元信息层」**：编号/时间/代码/标签用 mono，正文用无衬线（5/9 站）。
2. **双轨圆角**：控件 4–8px，标签/CTA 用 `9999px` 胶囊（orizon、kindi、emotion、atmospherik）。
3. **间距走 8 基数**：4 / 8 / 12 / 16 / 24 / 32；需要更细时用缩放系数派生，别手写 13px、19px。
4. **一个强调色打天下**：orizon 只用一个绿 #4ac300、emotion 只用一个紫 #9047ff、kindi 一个靛 #3d3dc2，
   其余全是中性灰阶。**两个以上高饱和并列 = 立刻像模板**。
5. **大标题负字距 + 紧行高**：H1 行高比 0.8–1.15，`letter-spacing: -0.02em ~ -0.04em`（kindi、twodo、emotion）。
6. **表格密度固定值**：th 14px/500、td 14px/400、行高 43–53px（shadcn dashboard 实测 53px）。
7. **控件高度固定值**：桌面后台 28–32px（linear 28/32、shadcn 32），移动触控 ≥44px。
8. **侧栏 232px、顶栏 73px**（linear 实测），不要写 250px/64px 这类「随手整数」。
9. **卡片优先用边框**：linear 页面里「有边框」的卡片 20 个、「有阴影」的 2 个。
   阴影只在浮层（dropdown/modal/toast）上出现。
10. **图片一律 lazy**，并给 `width/height` 或 `aspect-ratio` 防塌陷。
11. **令牌命名两派**（都成立，选一派用到底）：
    - 功能语义：`--bg / --surface / --border / --ink / --ink-soft / --ink-faint`（twodo）
    - 角色语义：`--color-text / --color-text-muted / --color-border`（supermodels）
    - 交互三连：`--primary / --primary-active / --primary-rgb`、`--status-danger / --status-danger-active`（emotion）
12. **状态与强调成对出现**：`--color-on-brand` 必须与 `--brand` 成对定义（本仓 `contrast_check.py` 也据此配对比度）。
13. **负扩散阴影替代边框**（即时设计）：`0 16px 16px -16px rgba(23,25,29,.2)` + `0 0 0 1px` 发丝环，
    阴影不外扩、卡片贴住底板；戏剧性大阴影（`0 50px 100px -20px`）**只**给浮起来的设备截图。
14. **输入与提交同容器**（即时设计）：外框 r15 白底 + 内钮 r8 品牌色，`focus-within` 把焦点环画在外框上，
    比两个独立控件更像「一件事」。
15. **颜色编码阶段**（即时设计）：三列流程用三色 pill（薄荷/薰衣草/珊瑚），颜色承载信息就不是装饰；
    第四种颜色出现时必须换编码方式，不是加色。
16. **同色成段**（即时设计）：`#f3f7fb` 连续 2–3 段再换白，交替换色会把页面切成条。
17. **毛玻璃头部无边框无阴影**（即时设计）：`rgba(255,255,255,.94)` + `saturate(2.5) blur(14px)`，88px 高；
    有促销条时头部 `top` 跟着走，促销条可关后要能回 0。

## 五、中文场景补充（无对应获奖样本，按可用性推导，标注为推断）

- 中文正文行高比取 **1.6–1.75**（西文 1.44 不可直接搬：汉字无升降部，1.4 会显挤）。
  即时设计是反面样本：13px / 1.50，字小行紧，靠「卡片多、段落短」掩盖——长文场景会难读。
- 中文字重只用 **400 / 500 / 700 三档**；600 在多数中文可变字体上缺失，会跳回 700。
- 中文标点与数字混排时数字用 `font-variant-numeric: tabular-nums`（表格金额列对齐）。
- 小程序/H5：正文 15–16px、次级 13px、最小 12px；触控目标 ≥44×44px；`viewport-fit=cover` + 安全区。
