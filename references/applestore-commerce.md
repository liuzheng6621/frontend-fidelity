# Apple Store 商品配置页：三层价格与 36px 色块 SKU

> 采样日期：2026-10-27；对象为 <https://www.apple.com.cn/shop/buy-iphone>（机型选择页）与 <https://www.apple.com.cn/shop/buy-iphone/iphone-17>（配置页），公开可访问、不登录、不加购。
> 视口：桌面 1440×900、移动 390×844（`isMobile` + `hasTouch`）。
> 读法：机型选择页跑了通用探针（1656 / 1123 元素）；配置页只做定向测量（价格、SKU、主按钮），**没有**跑通用探针，两页数字不可混用。

## 一、证据范围与纠偏

- 机型选择页 `buy-iphone`：1440 下 1656 个计量元素、56 张图（8 张 lazy）；390 下 1123 个元素、h1 从 80 降到 48。
- 配置页 `buy-iphone/iphone-17`：只量了 `RMB` 价格文本、颜色 SKU 圆点、主 CTA。容量档位（128GB/256GB…）的元素结构未被选中器命中，**容量控件尺寸未验证**。
- 加购弹层、送货信息、以旧换新估价、错误态均未进入——本次只停在「未加购」的静态配置态。
- 机型名会随发版变化（当前页面出现 iPhone Duo / 18 Pro / Air / 17 / 17e），URL 里的 `iphone-17` 是稳定锚点，重采时以它为准。

## 三、价格是三层，不是一层

这是电商详情页最该抄、又最容易被做丢的结构：

| 层 | 样式 | 内容示例 | 作用 |
| --- | --- | --- | --- |
| 主价 | 17 / 25 / **600** / `#1d1d1f` | `RMB 6799` | 决策数字，和正文同尺寸，只靠字重压住 |
| 分期 | 14 / 21 / 400 | `RMB 1,399 或 RMB 59/月 (24 期)` | 降低价格痛感，字号降一档 |
| 小字价 | 12 / 16 / 400 | 列表项 `RMB 8799` | 对比位，不参与主决策 |

三个要点：

1. **主价没有放大**。17px 和正文一样大，只用 600 字重和纯黑区分——这一点和国内电商（价格用 24–32px 红色）是两个流派。
2. **分期单独一行**，14px，不塞进主价后面。
3. **价格不支持颜色编码**：三层都是 `#1d1d1f`，没有红价、没有划线原价。促销信息在别处（这次未采到）。

## 四、SKU 选择器

- 颜色选项是 **36×36 的圆点**，`border-radius: 50%`，未选中 `border: 2px transparent`，选中描边用实色。
- 每个圆点有 `aria-label`（`lavender` / `薰衣草紫色`），可访问性合格。
- 圆点数量 5 个左右，横排一行；**不显示颜色名文字**，名字只在 `aria-label` 里。
- 容量档位未采到结构，只观察到它是另一组按钮（文本形），不是圆点——**两组 SKU 用不同形状区分**，这点值得抄。

## 五、色板

| 角色 | 值 | 用途 |
| --- | --- | --- |
| 主文字 | `#1d1d1f` | 标题、正文、价格 |
| 次级文字 | `#6e6e73` | 页脚栏题、说明 |
| 品牌蓝 | `#0071e3` | CTA、链接 |
| 浅底 | `#f5f5f7` | 区块交替底 |
| 纯白 | `#ffffff` | 卡片底 |
| 纯黑 | `#000000` | 少数深色块 |

- 没有第三个彩色。全站只有蓝色一种强调色，价格也不上色——和国内电商的「橙 + 红 + 促销黄」是两套世界观。
- 深浅交替靠 `#f5f5f7` 与 `#ffffff` 的 2% 亮度差 + 1px 边框，不靠阴影堆叠。

## 六、字阶

| 档 | 用途 |
| --- | --- |
| 80 / 48 | 机型选择页 h1（断点两档） |
| 28 / 24 | 区块标题 |
| 21 | 卡片标题（移动端出现） |
| 17 | 正文、价格主值 |
| 14 | 分期、按钮字 |
| 13 | 辅助 |
| 12 | 页脚栏题、小字价 |

- 8 档，比认证页多，因为要覆盖「大标题营销 + 小字参数表」两种场景。
- 行高比集中在 1.09（大标题，紧）到 1.47（正文，松）；大标题越紧越像「舞台」，正文越松越好读。
- 字体 `SF Pro SC`（系统字体，无 webfont），中文回退天然正确——这是苹果的独有优势。

## 七、控件高与圆角

- 控件高 **35 / 36 / 40 / 44 / 54** 五档，按用途分：35 是小号 filter、36 是药丸 CTA、40 是常规、44 是主 CTA、54 是购买大按钮。
- 移动端变成 **35 / 38 / 40 / 43 / 48**——不是等比缩放，主 CTA 从 54 降到 48，小件从 36 升到 38。
- 圆角 `18`（卡片）、`980`（药丸）、`56`（大面）、`6`（小件）；移动端少了 56，大面直接变直角或 18。
- **没有「统一圆角」**：四档并存且各司其职，这是苹果的做法，抄的时候要连着「哪个部位用哪档」一起抄。

## 八、它没做好的

1. **主价 17px 在小屏上不够醒目**：与正文同尺寸，靠字重区分，视力不佳的用户要扫很久。
2. **颜色 SKU 不显示名字**：只有圆点和 `aria-label`，明眼用户也不知道当前选的是什么颜色名。
3. **容量档位没有价格差提示**：选 128 还是 256 要自己回上面看主价变化，缺「+800」这类增量标注。
4. **页面 5211 高**：参数表、以旧换新、推荐位全塞在一页，移动端要靠长滚动。
5. **没有促销/划线价证据**：不能把「苹果没有促销设计」当成结论——只是这次没采到。

## 九、能搬 / 不能搬

能搬：

- **三层价格结构**（主价 / 分期 / 小字价），以及「主价不放大、只加字重」的克制做法。
- **SKU 用形状区分组**：颜色=圆点，容量=文字按钮，一眼能分清两组选择。
- 36×36 的色块、2px 透明边框占位（选中才上色），避免布局跳动。
- 控件高五档 + 圆角四档的「按部位分配」思路。

不能搬：

- 17px 主价（国内电商用户预期是红字大字，直接搬会被认为「价格不显眼」）。
- 无促销体系（国内详情页必须有划线价/券后价/倒计时，苹果这套没有对应件）。
- `SF Pro SC`（只有苹果能用；换站必须自备中文字体）。
- 全站单一强调色（国内电商至少需要「价格红 + 品牌色 + 促销色」三色）。

## 十、复现清单

1. 价格写成三层 DOM，不要用一行字符串拼接：`.price-main`（17/600）、`.price-inst`（14/400）、`.price-note`（12/400）。
2. 主价与正文同字号、只加字重；如果要放大，另立一档而不是临时改 `font-size`。
3. 颜色 SKU 用 36×36 圆点 + `border: 2px solid transparent`，选中换成实色；每个圆点带 `aria-label`。
4. 容量/S规格用文字按钮，和颜色圆点分两组，给组标题。
5. 主 CTA 44 高、r8、品牌蓝；移动端不缩到 40 以下。
6. 卡片用「1px 边框 + 单层轻阴影」，不要叠加三层阴影。
7. 用 `flow.mjs` 把「选颜色 → 选容量 → 价格变化 → 加购」写成流程，补上本次未验证的容量与加购态。

## 十一、对照：小米商城（反例）

同日在 <https://www.mi.com/shop/buy?product_id=10050236>（小米电视 S Pro）采了一份，作为**国内电商桌面密度**的对照：

| 项 | 小米（1440） | 苹果（1440） |
| --- | --- | --- |
| 元素数 | 635 | 1656（机型页） |
| 控件高 | **50** | 35–54 五档 |
| 圆角 | **2 / 50%** 两档 | 18 / 980 / 56 / 6 四档 |
| 字阶 | 12 / 14 / 16 / 18 / 22 / 24 | 12 / 13 / 14 / 17 / 21 / 24 / 28 / 48 / 80 |
| 价格色 | **`#c20000` 红** | `#1d1d1f` 黑 |
| 品牌色 | `#ff6700` 橙 | `#0071e3` 蓝 |
| 次级灰 | `#424242` / `#757575` / `#b0b0b0` | `#6e6e73` |

**关键反例**：`--viewport mobile` 传 390 后，探针量到 `innerWidth = 1228` —— 它的 `<meta viewport>` 把宽度锁死，页面上没有移动端布局；`m.mi.com` 也 302 回 `www.mi.com`，拿不到独立 H5。**小米商城 PC 商品页不能作为移动端参考**，这和 `design-evidence.md` 里已有的「viewport 锁 1420，390 屏整站缩到 27%」是同一类问题。

它能提供的是**国内电商桌面密度**：控件 50 高、圆角只有 2px 与 50% 两档、价格用红 `#c20000`、品牌橙 `#ff6700`。要抄「国内电商的价格存在感」，抄小米；要抄「价格分层与 SKU 结构」，抄苹果。
