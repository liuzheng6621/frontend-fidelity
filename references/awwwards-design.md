# Awwwards 首页：奖项目录站怎么让作品当主角

> 采样日期：2026-10-31；对象为 <https://www.awwwards.com/> 公开首页，不登录、不提交、不进入详情页。
> 视口：桌面 1440×900、移动 390×844 各一次；未做断点扫描，也未滚动到页尾逐屏量。
> 方法：REA 被动检查（CDP，DOM 4,073 节点 / 无障碍 1,336 节点 / 4 个脚本）+ 本项目 `probe-ref.mjs`（985 个计量元素）+ 定向盒模型脚本 + 视口截图。
> 读法：数值是当次计算样式与盒模型；首页内容每天换（Site of the Day），版式与令牌不随内容变。

## 一、证据范围与口径

- REA 结构证据：`banner` / `navigation` / `contentinfo` 三个地标齐全；无障碍树 1,336 节点，其中 112 个 link、40 个 heading、63 个 image、73 个 listitem。
- 通用探针：985 个元素、59 张图、20 张卡、98 个 `:root` 变量、**1 个动画**、0 张懒加载图。
- 卡片统计口径：20 张卡里 **0 张有阴影、0 张有边框**——层级完全交给图片与留白。
- 未覆盖：登录、Submit 流程、目录分页、详情页、hover / 滚动动效、深色（本站无深色主题）。
- 干扰项：截图右下有 Cookie 面板（400×172、padding 30、`#222`），它不属于版式，后文单独记。

## 五、版式节奏

桌面首屏的 y 坐标（1440 宽）：

```
0    顶栏（外层 71，内条 54）
105  「Site of the Day · Oct 30, 2026 · Score 7.31 of 10」行（14px，居中）
158  站名 h1（126.7px，高 127）
299  机构行（头像 32 + 名称 + PRO，高 39）
398  封面（1420×1065，左右各内缩 10）
1932 作品网格第一行（2 列 658，gap 30/20，卡高 550）
2996 第二组作品网格
5005 课程区（3 列 432，gap 20）
```

- 首屏 = 眉标 + 巨标题 + 机构行 + 封面，**没有副文案、没有 CTA 按钮**。作品本身就是 CTA。
- 区块之间靠 **80–120px 的空白**分隔，没有分隔线、没有背景块。
- 网格只有两种：**2 列 658**（作品）与 **3 列 432**（课程 / 目录），列距 20、行距 30；移动端全部塌成 358 单列，列距不变。

## 七、它没做好的

1. **59 张图，0 张 `loading="lazy"`**。首屏之后的作品图全部立即请求，移动网络下是明确的性能债。
2. **间距里混着 4.2px 与 20.6479px**。前者是 `0.3em` 一类相对值算出来的，后者是 em 嵌套的产物；和 8/20/30 的整数体系并存，说明令牌没有真正收口。
3. **输入框文字 13px**。42 高的控件配 13px 字，中文输入时偏小；这是英文界面的取舍，不该直接搬到中文后台。
4. **Cookie 面板压住首屏封面右下角**，且没有明显的关闭焦点管理；截图里正好挡住作品主体。
5. **卡片零壳**在图片质量差或加载失败时没有兜底——没有边框、没有底色、没有骨架，坏图就是一块空白。
6. **整页只有 1 个动画**。对「展示创意」的站来说这是克制，但也意味着所有交互反馈都压在 hover 的颜色变化上。

## 八、能搬 / 不能搬

**能搬**

- `#f8f8f8` 画布 + `#fff` 表面 + `#222` 文字的三级明度；不需要边框就能分层。
- 巨标题 `126.7 / 1.0 / 600 / uppercase`：一行装下站名，`letter-spacing: normal`，不靠负字距。
- 封面「近满宽 + 左右 10px 内缩、圆角 0」：比全出血更容易和栅格对齐。
- 2 列 `658` + 3 列 `432` 的双网格，gap 固定 `30/20`；移动端只改列数不改间距。
- 卡片不画壳：图 + 24px 信息区；适用于「作品本身就是内容」的站。
- 强调色只做事件标记（3 次），不做按钮底色。

**不能搬**

- 127px 标题搬到后台 / 文档站会直接把首屏吃掉；内容站的上限是 48–56。
- 0 懒加载、0 图片兜底：作品站可以赌图片质量，业务系统不行。
- 13px 输入字 + 42 高控件：中文与移动端都偏小，按 `component-spec.md` 用 14/16。
- 4.2px / 20.6479px 这类相对值：要么进令牌，要么删掉，别留在交付里。
- 无深色主题：本站只做浅色；需要深色时按 `visual-system.md` 的深色规则另起，不要用反相糊弄。

## 九、复现清单

1. 画布 `#f8f8f8`，表面 `#fff`，文字 `#222`；先只放这三种颜色，跑一遍对比度。
2. 顶栏 71（外层）/ 54（内条），左侧 logo、中部搜索 42 高、右侧两枚 42 高 r8 按钮（实心 + 描边）。
3. 眉标 14px 居中；站名 126.7px（移动 42）/ 1.0 / 600 / uppercase；机构行 14px。
4. 封面 `width: calc(100% - 20px)` 居中，圆角 0，高约 1065（或按 4:3 图）。
5. 作品网格 `grid-template-columns: repeat(2, 658px)`，`gap: 30px 20px`；390 下 `repeat(1, 1fr)`。
6. 卡片不设背景 / 边框 / 阴影；信息区 `padding-top: 24px`。
7. 强调色只给角标，最多 3 处；其余全走明度。
8. 跑 `audit.mjs`（明暗不适用，只跑 light）+ `contrast_check.py`；补 `loading="lazy"` 与坏图兜底，这两条别学它。
