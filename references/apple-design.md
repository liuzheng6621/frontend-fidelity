# Apple 中国首页设计蒸馏（实测，2026-10-27）

> 样本：`https://www.apple.com.cn/`，公开首页，1440×900 与 390×844；未登录、未爬全站。
> 证据：`apple.json`、`apple-mobile.json`、双视口全页图、`apple.jpg` 与 `audit-apple.json`，采样日期均为 2026-10-27。
> 补测：项目 Playwright + Edge，读取布局盒、computed style、`document.getAnimations()`，并只触发首个 CTA 的 hover 与键盘 focus。
> 截图是 2× DPR：桌面 2880×9254、移动 780×10956，对应 CSS 页高 4627 / 5478；下文尺寸统一用 CSS px。
> 证据边界：本版首屏是 iPad mini，顶部为浅色毛玻璃导航；未出现圣诞礼物横幅、环保/价值观卡。
> 本版 probe 是 16 个 `img`、0 个 `loading=lazy`，不是 56/51；不同采样版本不得拼接成一套“实测”。

这是一份**品牌产品首页 / 硬件发布页**样本：研究「全幅产品舞台 + 极薄界面层」，不是 SaaS 卡片首页。
未触发的菜单、轮播、active/disabled、读屏与 reduced-motion 均明确标为未验证，不把根变量声明当成可见效果。

## 一、气质一句话

**把界面削到只剩导航、标题、两颗 CTA 和页沟，让硬件摄影占满其余全部面积。**

1. 三个全幅主舞台先建立产品叙事，再用六格小舞台扩展产品组合，最后才进入长脚注。
2. 舞台没有卡片壳、圆角、投影或内描边；白页沟就是分隔，不需要再往外套容器。
3. 明暗是**逐块编排**：浅底用 `#1d1d1f` / `#0066cc`，黑底用 `#f5f5f7` / `#2997ff`。
4. 深色不是全站主题；`theme-dark` 只落在具体 tile 上，body、导航和页脚并不随它切暗。

## 五、布局、导航与逐模块顺序

### 1. 导航与活动条

桌面导航 fixed 44px，白底 80% + 毛玻璃；内部 1024px，左右 pad 22，文本 12px，链接盒高 44。
移动导航 48px，只保留 Apple、搜索、购物袋、菜单；搜索 / 购物袋 / 菜单各 48×48，Apple 入口宽 49。
`globalmessage-segment` 本版高度为 0；礼物条、黑导航和打开后的菜单表面均未验证，不能从别的首页版本补写。

### 2. 主舞台组：三个 692 / 500 的全幅章节

| 顺序 | 产品 | 桌面起点 | 移动起点 | 明暗与构图 |
| --- | --- | ---: | ---: | --- |
| 1 | iPad mini | y=44 | y=48 | 浅底；文案居舞台中部，左右产品夹持 |
| 2 | iPhone Duo | y=748 | y=560 | 浅底；顶部标题—副题—双 CTA，下接动态产品图 |
| 3 | iPhone 18 Pro | y=1452 | y=1072 | 黑底反白；相同顶部层级，产品摄影收尾 |

默认文案关系是产品名 → 副题 → CTA；主舞台 h2 与副题间距 6 / 4，CTA 组上间距桌面 17、移动 11。
首个 iPad mini 是 `content-center-large-up` 变体并多一段 callout，不要把所有舞台硬做成同一种垂直居中。

### 3. 六格小舞台组

桌面顺序按行：Watch Series 12 + Watch Ultra 4 → iPad Air + AirPods Pro 3 → MacBook Air + Trade In。
移动严格按同一 DOM 顺序单列展开，没有交换优先级；三幅 692 主舞台之后接六幅 580 / 500 小舞台。
桌面第一排两块继续黑底，后四块转浅底；明暗分界与产品分组一致，而不是黑白逐格棋盘交替。

### 4. 全幅图与移动裁切

桌面主图典型画布 **3008×692**，在 1440 舞台中居中后左右各溢 784；移动换为 **734×500**，在 390 中左右各溢约 172。
桌面小舞台图像典型为 **1262×580**，在 702 tile 中左右各溢 280；移动同样换 734×500 来源。
父 tile `overflow: clip`，图片绝对定位铺满；iPhone Duo 视频另用 `object-fit: cover; object-position: 50% 30%`。
可迁移的是「**独立 art direction + 过宽画布居中裁切**」，不是把桌面大图直接 `cover` 到手机后听天由命。

### 5. 页脚体系

页脚与主体之间仍留 12px 白沟，随后整段 `#f5f5f7`；桌面内容净宽 980，移动 358。
顺序为法律脚注 → 目录 → 选购帮助 → 版权 / 政策 / 备案；桌面脚注区 144.19 高，移动因换行为 304.19。
桌面目录为 5 个 196px 列，共 9 个 section；移动改为 9 个全宽折叠组，不按桌面五列硬压成缩字表。

## 六、组件状态与响应式

- 主 CTA：实蓝白字；默认无阴影、无 transform；hover 只变为 `#0076df`，computed transition 为 0s。
- 次 CTA：透明底，浅舞台 `#0066cc`、黑舞台 `#2997ff`；1px 描边与文字同色，形状仍是 980px pill。
- 首个 CTA 键盘焦点实测为 2px 蓝环、offset 3；active、disabled 与次 CTA hover 未触发，不补写数值。
- CTA 横向 gap：桌面主舞台 17，其余 14；桌面小舞台 CTA 组上间距 12，移动统一 11。
- 整舞台 `a.tile-link` 是绝对定位的指针快捷层，`aria-hidden=true`、`tabindex=-1`；真正 CTA 保持独立链接与键盘入口。
- 桌面类目导航是「产品链接 + 目录按钮」双控件；移动收进菜单。菜单展开、Esc、焦点圈定与返回均未触发。
- 移动页脚目录按钮宽 358、高 36；折叠内容未展开，不把桌面全部链接当作移动初始可见内容。
- 响应式只确认「2 列 → 1 列、692/580 → 500、导航 44 → 48、页脚 5 列 → 手风琴」，具体断点未验证。

## 七、动效：声明、计算值与真实播放分开

| 对象 | 实测 | 状态边界 |
| --- | --- | --- |
| 桌面导航链接 | color 0.32s，`cubic-bezier(.4,0,.6,1)` | 读取 computed；未展开菜单 |
| 移动导航底 | background 0.422s，delay .08s | 同上，未把 delay 算进时长 |
| 移动导航图标 | opacity / visibility 0.24s，delay .08s | 菜单按钮另有色 / 透明度 0.32s |
| 搜索结果与 chevron | 320ms / 240ms，linear | `getAnimations()` 中均为 finished，非当前可见循环动画 |
| 舞台 wrapper / 内容 / CTA | transition 0s，animation none | 没有给每张产品图补漂浮、缩放或滚动视差 |
| iPhone Duo 媒体 | 1 个 4s `video`，muted、playsInline、非 loop | 脚本按可见性播放；采样时桌面 paused、移动 playing |
| 轮播根变量 | slide 800ms、copy 600ms | 当前首页无可见轮播；只证明声明存在，交互未验证 |

probe 的 6 / 17 个 animation 包含隐藏导航里已结束的 CSSAnimation，不能解读为「移动比桌面更热闹」。
`prefers-reduced-motion` 回退、视频暂停控制和菜单完整动线未验证；复用时必须另做静态帧与减少动态效果方案。

## 八、性能与图片证据

本版 DOM 为 **16 `img`（含 1 个隐藏分享图）/ 15 `picture` / 53 `source`**，`loading=lazy` 为 0；这些是元素计数，不是请求数或字节数。
响应式来源把桌面与移动构图分开，减少了单纯裁图的构图风险，但不等于已证明按需加载、格式最优或流量最低。
桌面全页图最后一排有产品图未绘出，而移动图已绘出；这只能记为**截图时机 / 延迟渲染待核信号**，不能反推出 lazy 比例或加载时长。
iPhone Duo 还有桌面、移动两份 mp4；桌面审计记录两次 `ERR_ABORTED`，可能是媒体中止，不据此声称资源永久坏链。
审计本次 CLS 约为桌面 .000005、移动 .000016，只是一次采样；未测 LCP、INP、总传输量、缓存或弱网，全部标未验证。

## 九、可访问性与自动审计的正确读法

| 视口 | 汇总计数 | 重叠信号 | 其余关键项 |
| --- | --- | --- | --- |
| 桌面 | 9 error / 10 warn | 8 条 globalnav 链接 / 目录按钮；另 1 个 axe serious 计入 error | 8 clipped + 2 个 10px 购物袋徽标 |
| 移动 | 9 error / 31 warn | 8 条 tile-link / CTA；另 1 个 axe serious 计入 error | 8 clipped + 2 小字 + 20 小点击区 +“另 14 个” |

- 重叠是**结构信号，不是截图里的视觉 bug**：导航双控件和整舞台快捷层本来就与相邻控件共占矩形。
- 但导航不能直接判“误报”：定向 Tab 实测中，产品链接与 `pointer-events:none` 的目录按钮仍分别是 tab stop，需人工确认双焦点是否必要、焦点是否可见。
- tile-link 则因 `tabindex=-1` 被跳过；移动第 5 次 Tab 已到首个 CTA，桌面第 26 次到达。仍需读屏与触屏点按复核，不能只凭这项通过验收。
- `visuallyhidden` 的 h1 与隐藏导航文本触发 clipped 警告，属于检测器对视觉隐藏技术的局限，不应把隐藏标题“修”成可见大标题。
- 两端各 1 项 axe `label-content-name-mismatch`：`#globalnav-menubutton-link-bag` 可见 `0 +`，accessible name 为「打开购物袋」，二者需统一。
- 移动 CTA 和页脚折叠按钮高 36，低于本项目 ≥44 的验收线；这是真实可复用的反面，不是视觉重叠误报。

## 十、七处别照抄

1. **别把 36px 当移动点击区标准**：视觉上 pill 可以 36 高，实际可点区域应扩到至少 44，并保留间距与焦点环。
2. **别盲盖整卡链接**：tile-link / CTA 与导航双触发器都要做键盘、读屏、触屏命中复核；`aria-hidden` 不会自动解决交互冲突。
3. **别让可见文字与 accessible name 分家**：购物袋数量、加号和「打开购物袋」应有一致策略，同时处理 10px 徽标可读性。
4. **别把产品字标图当通用标题方案**：logo-image 要保留等价文本；普通硬件标题优先 live text，方便本地化、缩放和搜索。
5. **别直接搬 3008px 超宽画布**：按自身构图重做桌面 / 移动来源、尺寸与延迟加载，不能把本次 16/0 改写成想象中的 56/51。
6. **别把黑舞台升级成全站 dark mode**：`theme-dark` 属于单块；也不要把本版未出现的礼物条、环保卡或根变量绿写成可见模块。
7. **别复制未验收的媒体与菜单动线**：4s 视频、320/240ms 隐藏导航动画都不是 reduced-motion 已合格的证明，必须先补静态回退与暂停能力。

## 十一、可迁移手法与搬用步骤

可直接迁移的不是某个产品名，而是这组关系：**一幅一主角、两层短文案、至多两个行动、12px 页沟、明暗随素材、导航与脚注保持薄。**

1. 先排产品优先级与法务内容：3 个主舞台以内，后续才进双列小舞台；不要从卡片组件库倒推信息架构。
2. 建立一个可访问的页面 h1；主舞台产品名用 h2、小舞台用 h3，另设 `visuallyhidden` 时不把它误作视觉标题。
3. 只定义实测角色色：page / stage-light / stage-dark / ink / ink-inverse / link / link-inverse / action，不为凑体系发明十一档色阶。
4. 以 692 / 580 / 500 和 12px 页沟为起点做舞台骨架；按产品图重新确定 min-height，不把高度变成所有品牌的硬断点。
5. 为每个舞台分别输出桌面与移动图，保留安全区、焦点物和 alt；先定构图，再写 `overflow: clip`。
6. 文案限制为产品名、一句副题、可选一段 callout、至多两个 CTA；长卖点移到详情页，不在图片上叠 SaaS 功能卡。
7. 主 / 次 CTA 共用 pill 形状与双蓝链接体系，同时把移动有效点击区提升到 ≥44，并补齐 hover / focus / active / disabled。
8. 媒体默认给静态帧；视频必须 muted、playsInline、可暂停，并单独验证 reduced-motion，不用装饰性视差填补空洞。
9. 页脚按「法律脚注 → 目录 → 帮助 → 版权」组织；桌面多列、移动手风琴，但不沿用 36px 点击高度。
10. 最后做双视口全页图、图像晚加载复查、键盘 / 读屏 / 触屏复核与 axe；重叠告警逐条看 DOM，不以“参考站如此”豁免。

## 十二、与 wegic / jsdesign 的差异

| 维度 | Apple | wegic.ai | js.design |
| --- | --- | --- | --- |
| 核心表面 | 全幅产品舞台，界面极薄 | 纯黑叙事舞台 + 塑料按钮 | 冷灰蓝底板 + 白 / 彩纸卡 |
| 容器 | 产品媒体满视口；1024 只给导航 / 页脚 | 1280 内容容器 | 约 1277 内容容器 |
