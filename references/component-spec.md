# 组件规格（数字版）

从 0 生成时，组件**先定尺寸和状态，再画皮**。这份文件只给三样东西：尺寸、状态、禁忌。
皮（颜色/圆角/阴影）来自 `design-tokens.md` 的人格预设，别在这里另定。

三档密度（由人格决定，见 design-tokens.md）：

| 档 | 控件高 | 控件内边距 | 正文 | 表格行高 | 用在哪 |
| --- | --- | --- | --- | --- | --- |
| compact | 32 | 0 12 | 13 | 44 | 管理端、数据密集页 |
| regular | 36–40 | 0 16 | 14 | 48–53 | 通用产品页 |
| comfortable | 44–48 | 0 20 | 15–16 | 60+ | 消费端、营销页 |

**同一页面只用一档**。32 的输入框配 48 的按钮是最常见的「没对齐」来源。

---

## 1. 按钮

| 层级 | 底色 | 文字 | 用在哪 | 数量 |
| --- | --- | --- | --- | --- |
| primary | 品牌色实心 | 反白 | 页面唯一主动作 | 每屏 ≤1 |
| secondary | 浅底或 1px 描边 | 主文字色 | 次要动作（取消、导出） | ≤3 |
| ghost | 透明 | 主文字色 | 工具栏、行内操作 | 不限 |
| danger | 危险色 | 反白 | 删除、退出 | 不和 primary 并排 |

尺寸：sm 高 28–32 / pad 0 12 / 13px；md 高 36–40 / pad 0 16 / 14px；lg 高 44–48 / pad 0 20 / 15px。
图标按钮：容器 = 控件高方形（≥32 桌面，≥44 移动），图标 16–20，`stroke-width` 全站一致。
按钮组：相邻 8px；一组里只允许一个 primary。

状态（缺一个就是半成品）：

| 状态 | 桌面 | 移动 |
| --- | --- | --- |
| hover | 底色加深一档（约 -6% 亮度）或加 1px 内描边 | 无（包在 `@media (hover:hover)`） |
| active | 再深一档 + `translateY(1px)` 或内阴影侧壁归零 | 同上（`touch-action: manipulation` 去掉 300ms） |
| focus-visible | `outline: 2px solid brand; outline-offset: 2px` | 同 |
| disabled | 不透明 0.4–0.5，`cursor:not-allowed`，**不响应 hover** | 同 |
| loading | 保持原宽，`aria-busy="true"`，内容换 spinner（16px） | 同 |
| selected（toggle） | 实心或勾选图标 + `aria-pressed` | 同 |

禁忌：按钮里放两个图标；`loading` 时宽度塌陷；用 `<div>` 当按钮（键盘不可用）；
文字超过 6 个字还要求一行放下（移动端会被截）。

## 2. 输入框 / 文本域 / 选择器

- 高 = 控件高；`padding: 0 var(--pad-x)`；`border-radius: var(--radius-control)`；
  边框 1px `--border`，focus 时改成品牌色 + 2px 外环（用 box-shadow，不占盒模型）。
- 标签在**上方**，12–13px，与输入框间距 6–8；帮助/错误文本在下方 6–8，字号 12–13。
- 错误态：边框危险色 + 下方文案说明**怎么改**；同时 `aria-invalid="true"` + `aria-describedby`。
- 前缀图标：左侧 12 + 图标 16 + 间距 8，输入文字起点要跟着内移（用 padding-left，不要绝对定位压在文字上）。
- 文本域：`min-height: 88–120`，`resize: vertical`（允许纵向），行高 1.5。
- 选择器：和后端原生 select 视觉对齐；自绘下拉必须有键盘支持（↑↓/Enter/Esc）与 `role="listbox"`。
- 禁忌：placeholder 当标签；错误只变红不说原因；密码框没有显示/隐藏；输入框宽度随内容变。

## 3. 复选框 / 单选 / 开关

- 尺寸：勾选框 16–18，触控容器 ≥32（移动 ≥44）；单选圆点直径 8–10。
- 开关：轨 40×24 或 36×20，滑块 18–20，`transition: 160ms` 单条曲线。
- 标签可点（label 包住控件或 `for` 关联），整行可点。
- 禁忌：开关用于「提交后生效」的表单（开关暗示立即生效——要么立即生效，要么用复选框）；
  单选三个以上选项不用下拉（>7 才考虑下拉）。

## 4. 表格

- 表头：高 40–44，12–13px，次要色，字重 500–600，`position: sticky; top: 0`，底色不透明。
- 行：高 44（compact）/ 48–53（regular）；hover 底色 `--surface-hover`；选中行加左侧 2–3px 品牌色条或底色。
- 单元格 padding：`0 12–16`，首列左对齐内缩与页头文字对齐。
- 对齐：文字左、数字右 + `font-variant-numeric: tabular-nums`、状态/操作左或居中。
- 列宽：给 `min-width` 保底（如名称 200、金额 120、操作 96），容器 `overflow-x:auto`。
- 操作列：≤3 个图标按钮；更多收进「⋯」菜单；删除永远放最后并隔开 8–12px。
- 空/载/错：表格内嵌一行占满（`colspan`），高度 200–280，内容和 `§2.8 状态页` 一致。
- 禁忌：表头不吸顶；数字居中对齐；整页横向溢出；行内放 5 个彩色标签。

## 5. 弹窗 / 抽屉 / 气泡

| 类型 | 宽度 | 用途 | 必须 |
| --- | --- | --- | --- |
| modal | 400–560 | 确认、短表单 | 焦点陷阱、Esc 关闭、遮罩点击可配（危险操作禁止点遮罩关闭） |
| drawer | 360–480（右）/ 底部 60–80vh | 长表单、详情 | 同上 + 内部滚动不动背景 |
| popover | 200–320 | 菜单、筛选 | 点击外部关闭、跟随触发器、不超出视口 |

- 标题 16–18/600 + 关闭按钮（右上，32×32）；正文 14；底部操作右对齐（主行动最右）。
- 危险确认：标题写动作（「删除 3 条订单」），按钮写动词（「删除」），**不要用「确定」**。
- 禁忌：嵌套弹窗；弹窗里再放 tabs；遮罩透明度 <0.3（后面内容抢注意力）。

## 6. 提示（toast / inline alert）

- toast：右下或顶部居中，宽 280–360，圆角同容器，4–6 秒自动消失，可手动关，同屏 ≤3 条。
- inline alert：整宽或容器宽，padding 12–16，左侧图标 16–20 + 标题（可选）+ 一句话。
- 四种语气：success / warning / danger / info —— **必须配图标或文字标签**，不能只靠颜色。
- 禁忌：用 toast 报表单字段错误（那应在字段下方）；成功提示只写「操作成功」不说做了什么。

## 7. 标签 / 徽标 / 状态点

- tag：高 20–24，pad 0 8，12px，圆角 4–6（**不要胶囊**，除非是筛选 chip）。
- badge（数字）：min-width 18，高 18，12px，圆角 999；>99 显示 `99+`。
- 状态：圆点 8 + 文案，或浅底 + 深字（同色相）；同一系统的状态色全站固定。
- 禁忌：一个界面出现 6 种颜色标签；状态只有颜色没有文字。

## 8. 分页 / 加载更多

- 分页：显示「共 N 条」+ 页码（≤7 个）+ 每页条数选择；当前页实心，其余描边。
- 加载更多：按钮或滚动哨兵，加载中保持按钮宽度并显示骨架行。
- 禁忌：两者同时出现；只有「上一页/下一页」不给总数；总数在全表筛选后不更新。

## 9. 头像 / 缩略图

- 头像 24 / 32 / 40 / 48；圆形或不圆（跟随人格），**全站统一**。
- 缺图：取首字母 + 背景色（按名字 hash 取色板中的色），不要用灰色人形占位图。
- 缩略图：`object-fit: cover` + 固定 `aspect-ratio` + 底色占位；加载失败显示同尺寸占位块。

## 10. 进度 / 骨架 / 空态

- 进度条：高 4–6（细）/ 8（粗），圆角 999；不确定进度用条纹动画（`prefers-reduced-motion` 下停）。
- 骨架：底色 `--skeleton`，`border-radius` 跟随被替代元素，行高与真实内容一致；列表 ≥3 行。
- 空态：图标 32–48 + 标题 ≤12 字 + 一行说明 + 1 个行动（详见 `page-patterns.md §2.8`）。
- 禁忌：整页 loading 遮罩；骨架闪一下就消失（<200ms 不要显示骨架）；空态里没有行动。

## 11. 导航

- 顶栏高 56–72（管理端）/ 64–88（营销页）；品牌标高 28–32，与导航行垂直居中。
- 侧栏宽 200–280（管理端），折叠后 56–64；当前项：底色 + 左侧 2–3px 品牌色条 + 字重 500。
- 面包屑：13px 次要色，`/` 或 `›` 分隔，最后一项不可点。
- 禁忌：导航项 >8 个；当前项只靠颜色区分（要加底色/字重）；移动端顶栏放 5 个图标。

## 12. 数量步进（stepper）

移动端与电商的刚需。骨架里叫 `.co-qty` / `.m-qty`。

- 三段结构：减号按钮 / 数字输入 / 加号按钮，**按钮 ≥44×44**（不是 28）。
- 输入框宽 48–56，`text-align: center`，`font-variant-numeric: tabular-nums`。
- 必须钳位：`min=1 max=99`，到边界时对应按钮 `disabled`（不是点了没反应）。
- 隐藏原生 spinner：`-moz-appearance: textfield` + `::-webkit-*-spin-button { appearance: none }`。
- 禁忌：只有输入框没有步进（移动端键盘输入 2 位数字比点两下慢）；步进到 0（数量不能为 0，要么删行）。
- 无障碍：两个按钮都要 `aria-label="减少数量" / "增加数量"`，不要只放 `−` `+` 字符。

## 13. 列表项左滑操作（swipe-action）

Zarm 与 Android 都有，骨架目前**没有**——移动端列表的刚需缺口。

- 结构：容器 `overflow: hidden` + 内容层（`transform: translateX`）+ 操作层（绝对定位在右/左侧）。
- 容器 `touch-action: pan-y`（**不是 `none`**）：允许纵向滚动，只接管横向。写成 `none` 会把整页滚动锁死。
- 滑出距离 = 操作按钮总宽；超过阈值（约 40%）吸附展开，否则回弹。
- **必须给键盘等价操作**：每行保留一个「更多」按钮或右键菜单，不能只有手势。
- 同一时刻只允许一行展开；展开另一行时先收起上一行。
- 禁忌：把「删除」做成唯一的左滑项且没有二次确认；操作按钮用图标无文字（左滑本来就是隐藏操作，再省文字就猜不出）。

## 14. 下拉刷新（pull-to-refresh）

Zarm / GMU 都有，骨架目前**没有**。

- 三段式：下拉（跟手，阻尼 0.5 左右）→ 超过阈值（约 64px）松手触发 → 停在「加载中」高度，完成后回弹。
- 阈值没到就松手：直接回弹，不触发。
- `prefers-reduced-motion` 下取消回弹动画，只做位移。
- 顶部指示器要在安全区之内（`safe-top`），否则刘海压住转圈。
- 禁忌：下拉时整页跟着弹（要 `overscroll-behavior-y: contain`）；没有「已经是第一屏」的判断（在顶部继续下拉不该刷新）。

## 15. 顶部通告条（notice-bar）

- 高 36–44，单行可换行到两行，超出截断。
- 左侧状态图标（信息 / 成功 / 警告）+ 文案 + 右侧关闭按钮（44×44 命中区）。
- 关闭后写入 `localStorage`，同一会话不再出现——**否则每次进页面都弹一遍，等于没有关闭**。
- 禁忌：通告条做成常驻（那是 banner，不是通告）；关闭按钮只有 16px 图标。

## 验收（每个组件都跑）

1. 8 个状态都有截图（`screenshot.mjs` 拍不到就手动加个 demo 页）。
2. 键盘：Tab 到得了、Enter/Space 能触发、Esc 能退出、箭头能在组内移动。
3. 对比度：`contrast_check.py` 正文 ≥4.5、大字与图标 ≥3。
4. 200% 缩放：文字不重叠、不裁切、按钮不塌。
5. 触控：390 下每个可点元素 ≥44×44（`audit.mjs` 的 `small-tap-target` 会报）。
5. 触控：移动端可点区域 ≥44×44。
