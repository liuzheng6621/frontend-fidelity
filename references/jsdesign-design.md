# 即时设计 js.design 设计蒸馏（实测，2026-02）

采集：`https://js.design/`，1440×900 与 390×844，Edge headless，`document.fonts.status = loaded`。
`https://js.design/workspace` 需要登录：直接访问只渲染空壳（body 高 900、innerText 为空），
所以这份数据全部来自公开产品站首页。要蒸馏「画布页」本身，得先拿到登录态，见第十节。

## 一、气质一句话

**浅灰蓝底板上的一叠彩色纸卡。** 一页 12,984px 高，几乎全是留白 + 圆角 22 的白卡/彩卡轮换，
唯一的实色强调是 `#009dff` 蓝（全站 64 处），渐变只出现在 hero 一处。

四条可辨识特征：

1. **冷灰白而不是纯白**：底色在 `#ffffff`（53 处）和 `#f3f7fb`（10 处，冷到发蓝）之间成段切换，
   连续三段同底才换一次。
2. **零网络字体**：`document.fonts.size = 0`，全站系统字体栈。Inter / PingFang SC 只是栈里的优先项，
   没有一份 @font-face。
3. **一块彩色只当一块用**：`#83dde2` 薄荷、`#c0a3ff` 薰衣草、`#f8857e` 珊瑚，三色只做
   「流程阶段」编码，不当装饰撒。彩虹渐变仅 hero 一次，之后再没出现。
4. **所有卡片同一套阴影**：`0 16px 16px -16px` + `0 14px 20px 0` + `0 0 0 1px` 三条一组，
   28 处复用；戏剧性大阴影（`0 50px 100px -20px`）只给「浮起来的设备截图」，20 处。

字体栈：

```css
font-family: -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "PingFang SC", sans-serif;
```

实测 `document.fonts.size === 0`：没有一份 @font-face，连 Inter 都没有真加载
（`Inter` 只是栈里的一项，命中与否取决于系统装没装）。

**非整数字号的来源**：根字号 13px，其余全部 `em`。
`30.797 = 13 × 2.369`、`44.564 = 13 × 3.428`、`14.846 = 13 × 1.142`、`22.2857 = 13 × 1.714`。
照着抄会得到一串没法在设计稿里标注的数字——**学到的是「基准小 + em 放大」，不是那些小数**。

| 区块 | 高 | 上下内边距 | 底 |
|---|---|---|---|
| hero（含三屏视频轮播） | 788 | 0 / 0 | 彩虹渐变，`border-radius: 22.2857` |
| features（为什么选） | 1872 | 130 / 0 | 白 |
| signUp-area | 628 | 130 / 130 | `#f3f7fb` |
| highlight（AI 区） | 1152 | 0 / 130 | `#f3f7fb` |
| workflow（贯穿全流程） | 878 | 0 / 74.2857 | `#f3f7fb` |
| compare × 4 卡 | 537 / 张 | 40 / 40 | 自己 `#009dff`，其余 `#f3f7fb` |
| updated-log | 945 | 130 / 130 | 白 |
| footer | 1264 | 0 / 0 | 白 |

容器宽 **1277**（`max-width: 1280`），卡片几乎贴满容器，左右只留 1px 视觉余量。

三条值得学的：

1. **130px 是节奏单位**。所有大块上下各 130，没有一个例外；`74.2857` 是 em 化的 130（`130 ÷ 1.75`），仍属同一格。
2. **同色成段**。`#f3f7fb` 连续出现三段（signUp → highlight → workflow），不是「一白一灰」交替。
   交替会碎，成段才有「章节」感。
3. **渐变只给一个区块**。整页 12,984px 里，渐变只出现在 hero；其余全靠白卡和彩卡撑。

## 六、连它自己都没做好的（别抄）

1. **13px 正文 266 处**。中文 13px 已在可读性临界，它靠 `14.3` / `14.846` 混杂补位，
   实际阶梯是碎的：13 / 14.3 / 14.846 / 15 四个值挤在一档里，说不清谁是谁的下一级。
2. **非整数尺寸满地**（`11.1429` / `14.857` / `22.2857` / `30.797` / `37.05` / `44.564` / `37.1429`）。
   这是 em 缩放的副产品：设计稿上没法标注「22.2857px」，实现只能算，验收也没法对像素。
   要 em 就接受整数基准（如 14/16px），别让 13 × 1.714 这种数落进产出。
3. **标题层级倒挂**：`H2` 是 `19.5px/700`，`H3` 是 `44.564px/700`——h3 比 h2 大 2.3 倍。
   视觉上读得通（h2 当眼睛标用），但读屏大纲会认为页面主角是 h3，SEO 与无障碍都错位。
   要做小眼睛标就用 `<p>` 或 `<span>`，别占 h2。
4. **900 字重只给两块中文标**（`30.797/900`、`32/900`）。PingFang 与思源宋体都没有 900，
   浏览器只能伪粗，屏幕上一糊；而且只有这两块用 900、其余全 700，规律不成立。
5. **hero 文字是双份叠加**：`实时协同，提升各角色工作流中的效率` 在 DOM 里有两层，
   均 `opacity: 1`、`visible`、**没有 `aria-hidden`**，滚动动画未收敛时截图能看到两份残影。
   做滚动 crossfade 时，非当前层必须 `aria-hidden="true"` + `opacity: 0`。
6. **促销条 + 悬浮客服球双向遮挡**：顶部 40px 促销条把 fixed 头部顶到 `top: 40px`，
   右下 36px 客服球压在内容上；移动端页面高 13,259px，遮挡更明显。
7. **对比表的 ✓ 有营销水分**：「所有功能免费使用」打 ✓ 与免费版的实际限制不符。
   对比表要能被人当场验证，否则整张表失去说服力（本 skill `review-rubric.md` 有对应条目）。
8. **圆角七档没有递进关系**：7.43 / 8 / 10 / 11.14 / 12 / 13 / 14.86 / 20 / 22.29 / 1000。
   看不出「越大越外层」的规则，只能靠记忆。

## 七、能搬什么（迁移口径）

### 直接可搬（语言无关）

| 招式 | 怎么用 | 为什么成立 |
|---|---|---|
| **130px 区块节奏 + 同色成段** | 大块上下各 130；同底色连续 2–3 段再换 | 交替换色会让页面碎成条，成段才有章节 |
| **发丝环 + 负扩散阴影** | `0 16px 16px -16px` + `0 0 0 1px` 替代 border | 拐角不加粗、不占盒模型、卡片像贴上底板 |
| **戏剧阴影只给「浮起来的截图」** | 设备/截图卡用 B 套，普通卡永远用 A 套 | 两套混用才有层级；全用 B 会廉价 |
| **输入 + 按钮同容器** | 外框 r14.86 白底 + 内钮 r7.43 | 把两个控件声明成「一件事」，转化率高于分离布局 |
| **颜色编码阶段** | pill 三色只标流程三段 | 颜色承载信息就不是装饰 |
| **竞品对比：自己一列实色** | 主列品牌色实底白字，其余浅底 | 一眼看出「这是谁的表」 |
| **头部毛玻璃** | `rgba(255,255,255,.94)` + `saturate(2.5) blur(14px)`，无边框无阴影 | 88px 高滚动不动，内容从下面穿过 |

### 不能搬进管理端的

- `44.564` / `52` / `900` 这类展示字号与字重：管理端行高要留 32–40，塞不进 52px 标题。
- 彩虹网格渐变：一页只能有一次，后台没有「一次」。
- 彩色 pill 讲故事：后台用状态徽标（`review-rubric.md` 有密度与点击区要求）。
- 双份文字层做动画：后台不需要滚动叙事，还会带来读屏重复。

### 混合口径（同一个品牌，产品站与后台）

```
品牌色：#009dff（产品站实色）→ 后台 --brand-fill 需按 fillStep 取到 ≥4.5 的档（见 design-tokens.md）
底色  ：#ffffff / #f3f7fb（后台用 #f3f7fb 作 page 底、#fff 作 surface）
圆角  ：产品站 22.29（卡片）→ 后台 12（卡片）/ 8（控件），别把 22 带进表格
阴影  ：三件套可整段搬，负扩散的数值按后台密度缩到 12px/12px -12px
```

## 十、怎么重新采这个站

```bash
# 近似（字体/字号/颜色/圆角/间距/控件高度）
node scripts/probe-ref.mjs --url https://js.design/ --out .tmp/ref --name jsdesign --wait 5000
```

`probe-ref.mjs` 抓不到的，要补一段 `evaluate`：

- **零网络字体**：`document.fonts.size` —— 这里是 `0`，别被栈里的 `Inter` 骗了。
- **非整数字号的来源**：读 `getComputedStyle(document.documentElement).fontSize`（13px）再除。
- **双份文字层**：按文本内容找叶子节点，数出现次数、看 `opacity` 与最近的 `aria-hidden`。
