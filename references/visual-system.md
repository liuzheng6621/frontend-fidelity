## 视觉系统细则

### 中文排版（最容易露怯的地方）

- 字体栈先中后西：`-apple-system, "PingFang SC", "Microsoft YaHei", "Noto Sans SC", sans-serif`；
  只在真需要风格时插一款标题字体，正文永远用系统字体（可读 + 零加载）。
- **CJK 行高比拉丁文高**：正文 1.6–1.75，标题 1.3–1.4；行高 <1.5 的中文段落会糊成一团。
- 字号：正文 14–16px，辅助信息 12–13px（再小中文就难认），表格内 13–14px。
- 字重只留 400 / 500 / 700 三档。中文用 600 容易显脏，标题想强调优先加字号或颜色而不是字重。
- **数字对齐**：金额、编号、统计数字加 `font-variant-numeric: tabular-nums`
  + `font-feature-settings: "tnum"`，否则表格里列不上。数量用 `<b>` 配等宽数字，比换字体安全。
- 中英混排：`body { text-spacing-trim: space-all }` 是渐进增强，别依赖；手动在中英文之间留普通空格最稳。
- 两端对齐（`text-align: justify`）在中英混排下会出现大字洞，中文长文用 `text-align: justify; text-justify: inter-ideograph` 也要谨慎，默认左对齐最安全。
- 字距：正文、表格、按钮一律 `letter-spacing: normal`——中文字距天然均匀，拉开就散架。
  只有 **≥40px 的短标题**可以微放 `+0.01~0.02em`（实测 wegic.ai 在 48px 标题上用 +0.015em），
  且必须先看效果：放大字号本来就该「透气」，拉宽正文才是灾难。

### 色彩

- 60-30-10：60% 中性底、30% 次级面/文字、10% 品牌色。品牌色只给**主要行动**和选中态，不给装饰。
- 背景层次用极小的明度差（如 `#fff` / `#f8f8f7` / `#f1f1ef`），配 1px 边框分界；不要每层都加阴影。
- 深色不是反色：底用 `#0f0f0f`–`#1a1a1a` 而非纯黑，文字用 `#e8e8e8` 而非纯白（纯白刺眼、纯黑吃阴影）；
  品牌色在深色下要降饱和或提亮，直接用浅色版的品牌色会刺眼。
- **次级文字用「一个色相 + alpha」派生，不要另配三档灰**：`--ink: #000` 配 `.70 / .50 / .30 / .16 / .08` 五档透明度。
  深浅两套主题天然成立（深色段落把 ink 换成 `rgba(255,255,255,α)` 即可），也不会出现「灰和黑互相打架」。
  实测：wegic.ai 用十档 alpha；反面教材是它自己正文里又混进 43 处 `#4b5563`。**二选一，用到底。**
- 语义色不要只有色相差：成功/警告/危险同时用图标或文字标签，色盲用户靠颜色区分会失败。
- 所有前景/背景组合跑 `contrast_check.py`：正文 ≥4.5:1，大字与图标 ≥3:1。

### 间距与结构

- 用 4px 基准的间距变量，禁止在 CSS 里写 `13px`、`21px`。
- 容器最大宽度 + 居中：内容区 1080–1200px（管理端可到 1440px，但表格要能横向滚）。
- 相邻元素间距 ≥8px；分组间距用 24–32px；段落间距用行高自然分开，不额外加 margin。
- 圆角要成套：容器 12、卡片 10、控件 8、标签 4。**混用 6/8/10/12 会让界面显得没打磨。**

### 层级与阴影

- 层级顺序固定：page → surface → raised → popover → modal。每一级只比上一级亮一点（浅色）或暗一点（深色）。
- 阴影只给浮起元素，且和浮起程度匹配：`0 1px 2px` 给卡片，
  `0 4px 12px rgba(0,0,0,.08)` 给下拉，`0 12px 32px rgba(0,0,0,.16)` 给弹窗。
- 卡片不要又加阴影又加粗边框又加渐变——选一种分界方式。
- **发丝圈优先于 border**：`box-shadow: 0 0 0 1px rgba(0,0,0,.06)` 比 `border: 1px solid` 均匀
  （十字拐角不会变粗）、不占盒模型、不会让行高跳一像素。需要占位时才用 border。
- **内阴影可以做「厚度」**：`inset 0 -4px 0 rgba(0,0,0,.06)` 是按钮侧壁，hover 改 `-2px`、active 归零，
  再加一层 `inset 0 1px 4px 1px rgba(255,255,255,.2)` 做顶面鼓包——塑料键帽质感，不用渐变。
- 纯黑底上 **2px 实边比 1px 边框 + 阴影更清楚**（实测 `#0e0e0e` 卡 + `2px solid #232323` + r20 + 无阴影）。
- 渲染层级只允许三层固定结构：**一点落影 + 一圈内发丝高光 + 一圈外发丝环**。叠第四层就要问为什么。
- **负扩散阴影**：`0 16px 16px -16px rgba(23,25,29,.2)` + `0 0 0 1px` 发丝环，阴影不外扩、卡片贴住底板；
  戏剧性大阴影（`0 50px 100px -20px`）**只**给浮起来的设备截图（即时设计 20 处，其余卡片一律用前者）。
  两套分工才敢用大阴影，全站一套大阴影是廉价感的来源。
- **深度必须同时有偏移和模糊**：`0 1px 2px` 是深度，`0 0 4px` 不是（那是发光），`0 4px 0` 也不是（那是硬板）。
  想不出用哪种就选发丝圈——**幽灵卡（白底卡片放在白底页面上、只靠一点模糊阴影分辨）一律不通过**。
- **卡片圆角落在 12–16**；8 以下显得没做过，20 以上要成系统（不要 12/14/18 各来一次）。
  胶囊只给单行小控件（标签、开关、切换），别给卡片和输入框。
- **纯黑纯白当底色可以，纯值当文字/表面不行**：舞台可以 `#000`，但字用 `#f5f5f5`、
  表面用 `#0e0e0e`；浅色端同理，正文别用 `#000`（用 `#0a0a0a`–`#1a1a1a`）。
- **陈列区零阴影**（目录站/画廊站）：卡片靠 1px 线 + 固定比例成版，阴影全留给浮层。
  展品内部可以有自己的硬阴影（`6px 6px 0 0 #000`），但那是**展品**，不是展柜——
  **展柜一旦会浮起来，149 件展品就变成 149 个弹窗。**

### 动效

动效不是装饰，是**状态变化的证据**。四条底线 + 一张时长表，全部细节在 [`references/motion-spec.md`](motion-spec.md)。

- **只动 `transform` 和 `opacity`**；`top/left/width/height/margin` 会重排，`backdrop-filter` 大面积动会掉帧。
- **每个动画要能一句话说出动机**（层级 / 叙事 / 反馈 / 状态变化）。说不出就删。
- **可打断**：hover、快速连点、往回滚时不能"排队演完"；不要用 `animation-delay` 堆队列。
- **三档降级**：完整 / 减弱（`prefers-reduced-motion`）/ 关闭（低端机或用户手动，`--motion: 0`）。

| 场景 | 时长 | 缓动 |
| --- | --- | --- |
| hover / focus / 颜色边框 | 120ms | ease-out |
| 按下反馈 / 开关 / tooltip | 180ms | ease-out |
| 展开收起 / 抽屉 / modal | 240ms | ease-in-out |
| 区块入场 / 转场 | 400ms | ease-out |
| 一次性叙事（hero 逐字） | 600ms | ease-out |

- **进入用 ease-out，离开用 ease-in**，双向用 ease-in-out；`linear` 只给跑马灯和真实进度条；回弹只给直接操作，不给入场。
- **位移 8px 起、40px 封顶**；卡片 hover 抬 2–4px、图片放大 1.02–1.04（容器 `overflow: hidden`）、按下 `translateY(1px)` 或厚度归零。
- **交错 40–60ms、同组 ≤ 8 个、只演一次、≤ 1.2s 演完**；同一时刻只允许一个高注目动画。
- **入场用 `IntersectionObserver`，进度/视差用 CSS `animation-timeline`**；禁止 `window.addEventListener('scroll')` 驱动布局，禁止滚动劫持（营销页要做得给出口）。
- **无限循环每页 ≤ 1 个，且 hover / focus / reduced-motion 能停**；数字滚动只给真实数据且只滚一次。
- 自测：6× CPU 节流录 5 秒看掉帧 → Paint flashing 看有没有整块重绘 → 系统开「减少动态效果」刷新页面应无位移无循环 → `audit.mjs --reduced-motion`。
## 页面结构

### 内容列表 / 图墙

- **图墙里卡片不画壳**：图 + 一行标题 + 一两行副行，`background/border/radius/shadow` 都可以是 none。
  25 张图各套一个壳 = 25 层阴影，噪声翻倍。**壳只留给「少而重要」的东西。**
- **缩略图强制同比例**（`aspect-ratio` + `object-fit: cover`；设计稿预览用 `contain`）。
  不给比例、靠 `height: auto`，用户传一张长图就整行塌。
- **间距靠卡片 `padding`**：`grid gap: 0` + 卡片 `padding: 12px`，视觉间距 24px；
  改密度只动一个变量。列宽至少给到 220px，别写死「5 列 300」。
- **标题只给一行**（`nowrap` + ellipsis），副行两行封顶。行高要按行数算准，否则墙会错位。
- **筛选放分类条**：分类 ≥6 个用文字 tab（选中只换色），≤5 个才用胶囊；右侧放「共 N 个」。
- **hover 反馈给图**（缩放 1.02 / 描边 / 遮罩），别只给副行小字变色——用户靠图判断能不能点。
- **等宽网格，不做瀑布流**：瀑布流让每张图高度自由，用户扫读时眼睛找不到下一行起点。
  固定 `aspect-ratio`（内容社区用 4:3，作品集用 3:2）+ 等宽列，行距单独给（站酷 4 列 283、列距 24、行距 36）。
- **两级分类用形状区分**：一级 56px 文字 tab（选中 28×3px 短下划线），二级 31px 胶囊；
  两排并列时靠高度与轮廓分父子级，别靠颜色深浅。子类 ≥6 个时一级也可退化成纯文字（UI 世界做法）。
- **图墙页顶栏要 sticky**：顶栏 + 分类条并成一个 sticky 块（总高 ≤112px），否则滚过三屏就丢了筛选（站酷漏了这条）。
- **移动端 ≤640px 两列**，禁止横向滚动。判断标准：`scrollWidth === innerWidth`。

#### 陈列「一批彼此不同的东西」（风格库 / 模板库 / 主题库 / 组件变体）

- **卡片即预览，别截图**：每张卡用**该条目自己的 CSS** 现场渲染一套迷你 DOM，塞进固定比例的裁切框
  （`aspect-ratio: 4/3` + `overflow: hidden`）。截图会糊、会过期、窄屏失真；活预览永远准。
- **预览按容器宽度整体缩放**，不要缩字号：`container-type: inline-size` + `transform: scale(calc(100cqw / 371))`。
  直接写 10px 小字的话，390 宽下变 6px 还会被裁半行。
- **预览要 `aria-hidden="true"`**：读屏不该把 149 张卡里的 `ACTION` / `Read more` 念 149 遍；
  可点区域交给覆盖整卡的 `<a>`。
- **6px 四段色板条**：预览正下方 `display:flex; height:6px`，四段 `flex:1`，语义固定
  **背景 / 前景 / 强调 / 辅色**。一行 CSS 给每个条目一张"身份证"，比六行标签有效。
- **三个数字定死**：预览比例、色板高度、文本区高度（例：`4:3` / `6px` / `180px`）。
  **整齐来自公式一致，不来自内容一样**——这样才敢用直角、敢零阴影。
- **卡片 hover 只两笔**：边框转深 + 标题转强调色，无位移无阴影。卡内已经有一整幅彩色预览，再加动效就是噪声。
- **一页两套版式**：列表页（陈列）与详情页（说明书）必须同族不同形——
  列表用 36px H1，详情用 60px H1 / 行高 1.0；列表页定版式，详情页定内容。
- **详情页色板给「角色名 + hex」**（`Primary #000000`），不给一串色块；
  长提示词/代码块必须折叠或分块 + 目录跳转，别做成一屏两万像素的 `pre`。
- **「一批同质素材」走另一条路：界面隐形**。当内容本身就是成品（真机截图 / 照片 / 实物图），
  不要给每张图套壳、不要加边框阴影，让它们并排成墙；界面只保留页头、筛选条与计数。
- **数字当标题**：有真实数量（多少条、多少个、多少张）时，把它放成页面最大的字并单独上色，
  说明文字退到 18px 灰。比写「海量」「一站式」有效，也更容易验收。
- **一个正方形尺寸走全场**：头像、图标、墙里的缩略图共用一个尺寸（例 80×80 / r24），视觉重量才对得齐。
- **视觉裁切必须留出口**：把一条横带裁成 1.8 张很好看，但必须配「+N」/ hover 提示 / 可键盘进入的「查看全部」，
  否则等于内容丢失（UI Notes 的病）。
- **全站只有一个行高策略**：内容站可以整站 `line-height: normal` 换来「工具感」，
  但正文一旦超过 40 字就必须回到 1.5 以上——两者不能同时存在。

### 列表/管理端

- 三段式：**页头（标题 + 说明 + 主行动）→ 过滤区 → 数据区**。页头不要塞进卡片里，那是常见的一层多余嵌套。
- 表格：表头吸顶（`position: sticky`）、行 hover 有底色、数字右对齐并 `tabular-nums`、
  操作列固定在右侧、**列宽用 `min-width` 保底不许挤压到换行**。
- 表格容器 `overflow-x: auto`，让表格自己横向滚，不要让整页横向溢出。
- 每行操作超过 3 个就收进「更多」菜单；删除类操作永远不和编辑挨着放。
- 分页/无限滚动二者选一，并显示总数——用户需要知道「一共有多少」。

### 空、载、错三态（每个数据区都要有）

- **加载**：骨架屏优先于转圈（骨架要保持最终布局，否则会 CLS 跳动）。列表至少给 3–5 行骨架。
- **空**：一张小插画或图标 + 一句说明 + **一个主行动**（「新建订单」）。只说「暂无数据」是偷懒。
- **错误**：说清发生了什么 + 可重试按钮；不要把原始错误码直接甩给用户。
- **无权限**：和空状态区分开——「你没有该模块权限」和「这里还没数据」是两件事。
- 首次加载用骨架，刷新用顶部细进度条，不要把整页变成 loading 遮罩。

### 表单

- 标签固定在输入框上方（不要用 placeholder 当标签——输入后标签就消失了）。
- 校验时机：失焦校验 + 提交时全量。错误文案写在字段下方，**用文字说明怎么改**，不要只说「格式错误」。
- 主按钮右、次按钮左（桌面）；移动端主按钮通栏放底部，避开键盘和手势区。
- 必填标记 + 帮助文本的位置在整套表单里必须一致。
- 危险操作（删除/清空）二次确认，确认按钮上写明动作（「删除订单」而不是「确定」）。

### 登录墙（管理端几乎必踩）

- 截图/审计前先 `auth.mjs` 导登录态，否则截到的是登录页而你以为在审业务页。
- 用 `--expect-text` 断言目标页特征文案，被重定向回登录页会直接报 error。
- 登录页本身也要审：密码框、错误提示、记住我、忘记密码入口别缺。

## Logo 与品牌

- 拿到图先 `crop_logo.py --check` 看长宽比和包围盒，确认没被裁坏。
- 裁边 → 加留白（`--pad`，一般 8–24px，让标在容器里不贴边）→ 导出所需尺寸（`--height`）。
- favicon/头像用 `--format square --side 512` 生成正方形透明底。
- **CSS 里永远不要用固定 width+height 硬拉一个比例不对的图**。用 `width:auto;height:<h>px` 或
  `aspect-ratio` 保持比例，让浏览器自己算；`audit.mjs` 的 `logo-distorted` 检查会抓拉伸。
- 深色主题下深色 Logo 会消失：准备两版（浅色版 / 深色版），或用一个带底色容器托住。
- 页面顶部品牌区：Logo + 产品名 + 可选副标题，三者基线对齐；Logo 高度与导航行高对齐（一般 28–40px）。

## 图片与视觉资产

- 每张图必须有 `width`/`height` 属性或 CSS 固定尺寸，**否则一定贡献 CLS**（`audit.mjs` 的 CLS 检查会抓到）。
- 首屏图用 `loading="eager"` + `fetchpriority="high"`，其余 `loading="lazy"` + `decoding="async"`。
  注意：懒加载图在截图里会空白，所以 `screenshot.mjs` 会先滚动一遍——别自己写死 `loading=lazy` 又不滚动就截图。
- 图片容器用 `aspect-ratio` 预留空间，配一个底色或模糊占位，避免加载后跳版。
- 图标统一来源：一个图标集（Lucide/Heroicons/Tabler 选一个）、统一线宽（1.5 或 2）、统一 24 网格。
  混用两套图标集是「看起来不专业」最快的方式。
- 插画/装饰：能删就删。删不掉就降饱和降对比，不要和内容抢注意力。
- 静态资源 >300KB 就该压缩或转 WebP/AVIF；`hygiene.mjs` 会列出来。

## 控件与状态

每个可交互元素都要有这 8 个状态，缺一个就是半成品：

`default` / `hover` / `active` / `focus-visible` / `disabled` / `loading` / `selected` / `error`

- `:focus-visible` 必须有可见轮廓：`outline: 2px solid var(--brand); outline-offset: 2px`。
  **`outline: none` 是禁用项**——要自定义就用 `:focus-visible` 配 box-shadow，而不是删掉焦点。
- `disabled` 降不透明度到 0.4–0.5 并 `cursor: not-allowed`，同时**不要让它还能 hover 变色**。
- `loading` 时按钮保持原宽（内容换成 spinner 或加 `aria-busy`），否则布局会跳。
- 按钮层级只留三档：primary（实心）/ secondary（描边或浅底）/ ghost（无底）。同一屏不要出现两个 primary。
- 点击区最小 32×32（桌面）/ 44×44（移动），图标可以小，容器要够大。
- 破坏性操作（删除、退出登录）用危险色，且不和主行动并排。

## 响应式

- 断点跟着布局崩点走，不跟设备型号：常用 `640 / 768 / 1024 / 1280`。先写移动端再向上加，比反向减法稳。
- 容器查询（`@container`）优先于媒体查询——组件应该按自己拿到的宽度适配，而不是整个视口。
- 移动端（H5/小程序）重点：**单手可达区（屏幕下方 1/3）**、底部安全区
  （`env(safe-area-inset-bottom)`）、100vh 在移动浏览器里的跳变（用 `100dvh`）、输入框聚焦时键盘遮挡。
- 表格在窄屏不要硬缩：改成卡片列表（每行一个 `<div>` 堆字段），或只留关键列 + 「展开」。
- 触屏上 `:hover` 会粘住：hover 样式包在 `@media (hover: hover)` 里。
- 禁止横向滚动（`body` 层）；`audit.mjs` 的 `h-overflow` 会报具体溢出像素。

## 深色模式

- 用变量切换，不要在组件里写 `!important` 覆盖：`:root { --bg: #fff } .dark { --bg: #121212 }`。
- 支持三态：跟随系统（`prefers-color-scheme`）/ 手动浅色 / 手动深色，手动选择存 localStorage 并在首帧内联应用（避免闪白）。
- 深色下：不纯黑、不纯白、阴影几乎无效（改靠边框和背景明度差）、图片和插画需要降亮度（`filter: brightness(.9)` 或换深色版）。
- 两套主题都要跑 `screenshot.mjs --themes light,dark` 和 `contrast_check.py`——深色主题的对比度是独立问题，不会因为浅色通过就自动通过。

## 可访问性（不用背标准，跑脚本）

人工只做四件事，其余交给 `audit.mjs`（内置 axe-core）：

1. Tab 从头走一遍：焦点顺序符合阅读顺序、焦点永远可见、弹层有焦点陷阱、Esc 能关。
2. 所有图标按钮有 `aria-label` 或 `title`。
3. 表单控件都有关联的 `<label for>` 或 `aria-label`；错误用 `aria-describedby` 关联。
4. 尊重「减少动效」：`@media (prefers-reduced-motion: reduce)` 里把过渡/动画降为 `0.01ms`。
   `audit.mjs --reduced-motion` 会抓仍然无限循环的装饰动画。

## 避免（这些是「像 AI 生成的」信号）

下面是最高频的条目；完整清单、三档旋钮（VARIANCE / MOTION / DENSITY）、34 条 pre-flight 与中文站改写条款在 `references/anti-slop.md`，工艺底线（九条 verify + 深度三选一 + 原生表面）在 `references/craft-floor.md`。

- 大标题配「✨ 副标题 ✨」式emoji 堆砌；正文里塞 emoji 当图标。
- 全页面都是渐变（尤其紫蓝渐变）+ 全员 16px 圆角 + 全员大阴影。
- 每个卡片都带一句无关励志小字；装饰性英文 all-caps 小标题滥用到每个区块。
- 三个并排卡片里塞三段长度相近的假文案（典型的占位感）。
- 用 `border-radius: 9999px` 把所有东西做成胶囊，包括输入框和表格行。
- 无意义的动效：元素逐个淡入、数字滚动、鼠标跟随光斑。
- 用 `!important` 打架、用 `margin-left` 硬推、用 `position: absolute` 拼布局。
- 中文里混杂半角标点，或全角标点用错（句号「。」、顿号「、」、书名号《》）。
- 把设计稿的像素值原样搬进 `px`：先确认稿子是什么分辨率，再换算成相对值。
- 只做浅色就交付；只做 1440 宽就交付；只做 happy path 就交付（空/错/载三态缺失）。
- **用空白当内容**：靠 `margin-top: 1600px` 之类把页面撑长制造「高级感」（wegic 的 AI 段落就是这么干的）。
  信息页与管理端里这等于让用户多滚三屏。
- 预载一堆没用到的字体：把 `font-family` 当设计感来源，`document.fonts` 里一半是 `unloaded`。
- 促销文案做成一套独立视觉（高饱和渐变条 + 倒计时角标 + 弹窗），和整站语言割裂——这是广告位，不是设计。
- **用 em 缩放把尺寸推成非整数**（22.2857 / 30.797 / 44.564）：设计稿没法标注，实现只能算，验收也没法对像素。
  要弹性就取整数基准（14/16px）再按倍数放大，别让 `13 × 1.714` 落进产出。
- **标题标签与视觉大小不一致**：把 `<h2>` 做成 19.5px 的眼睛标、让 `<h3>` 当 44px 的主角（即时设计就是这样），
  读屏与 SEO 都按标签走，大纲会倒挂。眼睛标用 `<p>` 或 `<span>`。
- **用「viewport 锁宽度 + 等比缩小」当移动端**：`width=1420` 让 390 屏整站缩到 27%，表面不横向滚动，
  实际正文物理高度只剩 3.5px（UI Notes 的做法）。这比横向溢出更难查，验收时量 `scrollWidth === innerWidth` 之外
  还要量**最小可读字号**。
- **内容站删掉 h1 与页脚**：最大的字用 `div` 撑、底部没有备案/隐私/联系方式（UI Notes 只剩一个 `box:0` 的隐藏链接）。
  两样都是底线结构，验收清单里直接判不通过。
- **用裁切藏内容却不留出口**：一条横带只露 1.8 张、hover 零反馈，用户不知道后面还有（UI Notes）。
  裁切可以，但必须给「+N」/ hover / 键盘可达的「查看全部」。
- **用 900 字重做中文标**：PingFang / 思源都没有 900，浏览器只能伪粗，字缘发糊。中文字重 400/500/700 封顶。
- **滚动动画的双份文字层不隐藏**：非当前层必须 `aria-hidden="true"` + `opacity: 0`，
  否则动画未收敛时能看到两层残影，读屏还会读两遍。
- **给图墙每张图套卡片壳**：图上加背景、圆角、阴影，一屏 20 张就是 20 个浮块（UI 世界 1 处阴影是对的）。
- **用截图做卡片预览**：一批"彼此不同"的东西用截图陈列，两周后全过期，窄屏还糊；用真 CSS 渲染。
- **预览区里放真文字却不缩放**：10px 的字在 390 宽下变 6px，再被 `overflow: hidden` 裁掉半行（StyleKit 踩了）。
- **深色开关点了没反应**：有按钮无效果比没有按钮更伤；要么成套做，要么别放入口（StyleKit 的半成品）。
- **无限滚动不留出口**：只显示「已显示 24 / 149」没有「加载更多」，键盘与读屏用户永远到不了下一批。
- **靠 `height: auto` 排缩略图**：用户传一张长图整行塌，必须 `aspect-ratio` + `object-fit`。
- **「PC 版直接缩小」当移动端**：`meta viewport` 有但布局写死 1500px，390 宽下每卡 64px、
  还要横向滚（UI 世界、站酷都是这样）。验收标准就一条：`scrollWidth === innerWidth`。
- **列表 hover 只让小字变色**：卡片本体（尤其是图）零反馈，用户不知道能不能点。图要缩放或压暗。
- **长列表顶栏不 `sticky`**：滚两屏后分类、排序、搜索全消失，用户只能滚回顶部。
- **把 `0.8px` 之类的发丝宽当固定令牌**：它在 DPR1 或小数缩放下会发虚，统一 `1px` + ≤8% 黑更稳。
- **hero 里放版本号 / 装饰文字条 / 滚动提示**：`V0.6 · BETA`、`BRAND. MOTION. SPATIAL.`、`Scroll to explore`、
  `Lisbon, 14:23 · 18°C` —— 除非它承载真实状态（构建信息、cookie、可点的粘底导航），一律是装饰。
- **小节编号当标题**（`00 / INDEX`、`Step 01`、`01 / 4`）：用户数得出来；用动词当标签（"安装"、"上线"）。
- **CTA 下方挂一行小字**（"无需信用卡 · 5 分钟接入"）**和信任微条**：CTA 已经说了你干什么，
  小字是在替它道歉；信息放在 CTA 之后的内容里。
- **用 div 拼假产品 UI 当预览**：假侧栏假图表假表格，一眼假、维护零收益；要预览就用真组件或真图。
- **三把锁破功**：中途反色（先浅色后深色 CTA 带）、二色强调（品牌色 + 一个"辅助"高亮）、
  圆角每节换一套——这是「越做越丰富」的典型下场。
- **用 `window.addEventListener('scroll')` 驱动布局或动画**：每帧都跑、易卡顿，还会和滚动惯性打架；
  用 `IntersectionObserver`、CSS `animation-timeline` 或库的 scroll hook。
- **把两三个动效库混在同一棵树上**（GSAP + motion + Lottie）：抢同一批帧，最后只能靠延时凑。
- **声明了动效却没有真动**（旋钮值喊得高、页面全静态）：半成品比没有更伤，宁可说"这个站是静态的"。
