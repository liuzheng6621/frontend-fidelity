# 设计令牌（从 0 生成时的定数表）

这份文件回答「第一次定数字定多少」。五套人格预设可以直接抄，也可以按 §3 的数学从品牌色推出来。

配套：`page-patterns.md`（定骨架）、`component-spec.md`（定组件尺寸）、
`copy-and-content.md`（定文字）、`scripts/scaffold.mjs`（把这里的选择吐成 `tokens.css`）。

---

## 一、先做三个决定

| 决定 | 选项 | 影响 |
| --- | --- | --- |
| 品牌色相 | 一个 hue（0–360），不要两个 | 全部品牌色从它派生；第二个品牌色等于没有品牌色 |
| 中性温度 | 冷（220）/ 中性（0）/ 暖（35–45） | 决定背景与边框偏蓝还是偏黄，是「理性」与「亲和」的主要分野 |
| 密度 × 圆角 | compact+小圆角 / regular+中 / comfortable+大 | 一次定死，全站不混 |

三个决定其实是三个客户类型：**管理端＝冷中性+compact+小圆角**；**内容/品牌＝中性+regular+极小圆角**；
**消费/亲和＝暖中性+comfortable+大圆角**。选错这一层，后面所有细节都救不回来。

## 二、五套人格预设（可直接抄，也可 `scaffold.mjs --persona` 生成）

数字来自实测：`rational` 对齐 shadcn/linear/cal.com；`editorial` 对齐 stripe（H1 48px/1.15/**字重 400**）；
`warm` 对齐 duolingo（主色 #58cc02、控件高 50、圆角 12 与 2 两级）。

### 2.1 深度语言三派（卡片怎么「站起来」）

| 派 | depth | 静止 | hover | 按下 | 谁在这么干 |
| --- | --- | --- | --- | --- | --- |
| 发丝环 | hairline | 6% 墨的 1px 环 | 环加深到 45%，位移 0 | 环回原样 | shadcn / linear / 多数样本 |
| 软阴影 | soft | sh-1 + 发丝 | sh-2，上浮 2px | 落回 sh-1，下压 1px | Stripe / Apple / Wegic |
| 硬阴影 | hard | 4px 4px 0 实心墨 | 6px 6px 0，左移 1px | 2px 2px 0，右压 2px | 猫叫兽 / Neo-Brutalist 派 |

**一个页面只能有一派。** 混用是「廉价」的直接来源：同一屏既有 4px 硬阴影又有 24px 软阴影，眼睛找不到规则。
scaffold.mjs 已把这一层做成 persona 字段（hairline / soft / hard），生成的 depth.css 会同时给出三件套
（rest / hover / active）与位移量，**别再手写**。

## 三、从品牌色生成色阶（不靠手调）

给定 `hue` 与 `sat`（0–100），按下表取每档的 `L` 与 `S` 系数，输出 50–950 共 11 档：

| 档 | L% | S 系数 | 典型用途 |
| --- | --- | --- | --- |
| 50 | 97 | 0.30 | 品牌底纹、选中行 |
| 100 | 94 | 0.42 | 浅底标签 |
| 200 | 88 | 0.55 | hover 浅底 |
| 300 | 79 | 0.70 | 描边、图表次色 |
| 400 | 68 | 0.88 | 深色主题下的品牌色 |
| 500 | 56 | 1.00 | 主色（按钮底） |
| 600 | 47 | 0.96 | hover / 主色深 |
| 700 | 38 | 0.88 | active、链接文字 |
| 800 | 31 | 0.78 | 深色底上的强调 |
| 900 | 25 | 0.70 | 图表主色深 |
| 950 | 17 | 0.60 | 极深底 |

实现就三行：`hsl(h, s*coef, L)`。**不要**只用一个主色 + `opacity` 生成整套（会在浅底上发灰）。
主色只给「主要行动 + 选中态 + 一个强调数字」，其余不涂色。

中性 ramp 用同一张 L 表、`hue` 取中性温度、`sat` 取 2–8%，**不要纯灰**（纯灰在任何屏幕上都会显脏）。

语义色固定（不要用品牌色兼任）：成功 `152 / 45%`、警告 `38 / 92%`、危险 `0 / 72%`、信息 `208 / 88%`。
每档再派生一个浅底（L 96 / S 40%）和一个深字（L 32 / S 80%）。

## 四、间距尺度

4px 基准 × 密度系数（compact 1、regular 1.25、comfortable 1.5），取整到偶数：

```
--s-1: 4    --s-2: 8    --s-3: 12   --s-4: 16
--s-5: 20   --s-6: 24   --s-7: 32   --s-8: 40
--s-9: 48   --s-10: 64  --s-11: 80  --s-12: 96
```

- 组件内边距：控件高的一半左右（32 高控件用 `0 12`，40 用 `0 16`）。
- 相邻元素 8，分组之间 24–32，区块之间 48–128（见 §2 表）。
- **禁止**出现 13 / 17 / 22 / 27 这类值。审查时 `grep -E "[0-9]+px"` 看有没有漏网的。

## 五、字阶

用比例推，档位 6–8 个封顶（含行高与字重）：

| 档 | rational（1.2） | editorial（1.333） | warm（1.25） | 用途 |
| --- | --- | --- | --- | --- |
| xs | 11 / 1.5 | 12 / 1.6 | 12 / 1.5 | 辅助、角标 |
| sm | 12 / 1.5 | 13 / 1.6 | 13 / 1.5 | 标签、表格头 |
| base | 14 / 1.55 | 16 / 1.6 | 16 / 1.45 | 正文 |
| lg | 16 / 1.5 | 19 / 1.5 | 18 / 1.4 | 卡片标题 |
| xl | 20 / 1.4 | 24 / 1.35 | 22 / 1.35 | 区块标题 |
| 2xl | 24 / 1.3 | 32 / 1.25 | 28 / 1.3 | 页面标题 |
| 3xl | 32 / 1.2 | 44 / 1.15 | 36 / 1.2 | 营销小节 |
| 4xl | 40 / 1.15 | 56 / 1.1 | 48 / 1.15 | Hero |

- 大标题用 `clamp()` 做流体：`clamp(32px, 5vw, 56px)`，**上限就是上面那档**，别在 1440 上冒出 96px（营销站除外）。
- 中文行高比拉丁高 0.1–0.15；表格内可以压到 1.3，正文不要低于 1.5。
- 字重用 400/500/600/700；editorial 的大标题用 **400** 是对的（实测 stripe H1 48px 字重 400），
  中文用 400 会显轻，折中到 500 并加大字号。
- 字距：正文/表格/按钮 `normal`；≥40px 标题可 `-0.01 ~ -0.02em`（拉丁）或 `+0.01em`（中文短标题，见 SKILL.md）。

## 六、圆角与阴影必须配对

| 人格 | 圆角档 | 阴影策略 |
| --- | --- | --- |
| rational | 4（标签）/ 6（控件）/ 8（卡片）/ 12（弹窗）/ 16（大容器） | 极轻：`0 1px 2px rgba(0,0,0,.06)` + 发丝圈；靠边框分层 |
| editorial | 2 / 3 / 4 / 6 | 几乎不用阴影；用 1px 边框 + 底色差 |
| warm | 8 / 12 / 16 / 24 / 999（仅胶囊 CTA） | 可见阴影，带底色相：`0 8px 24px -8px hsl(h 60% 40% / .28)` |

阴影结构固定三层（见 SKILL.md）：一点落影 + 一圈内发丝高光 + 一圈外发丝环。叠第四层就要问为什么。

## 七、动效

一条曲线，三个时长：

```
--ease: cubic-bezier(.33, 1, .68, 1);
--dur-fast: 120ms;   /* hover、焦点 */
--dur-base: 200ms;   /* 展开、切换 */
--dur-slow: 280ms;   /* 抽屉、弹窗 */
```

- 只动 `transform` 与 `opacity`；动 `height` 用 `grid-template-rows` 技巧，别动 `height`。
- 入场动画只给首屏一次，滚动逐块淡入很容易过量（而且移动端往往全被浏览器特性关掉）。
- 必须有 `@media (prefers-reduced-motion: reduce)` 降级（`0.01ms`）。

## 八、命名约定（和 Tailwind / 组件库对接）

```
--bg         页面底           --surface    卡片/面板
--raised     抬升面           --border     1px 边框色
--ink        主文字           --ink-2      次级文字（ink 72%）
--ink-3      弱化文字         --ink-4      占位/禁用
--brand      品牌 500         --brand-600  hover
--brand-50   品牌浅底         --on-brand   品牌底上的文字
--ok --warn --danger --info  （各带 -bg 浅底与 -ink 深字）
--r-xs --r-sm --r-md --r-lg --r-xl --r-pill
--sh-1 --sh-2 --sh-3
--control-h --control-h-sm --pad-x
```

Tailwind v4：把这些写成 `@theme` 变量，类名 `bg-surface` / `text-ink-2` 自动可用；
Tailwind v3：`theme.extend.colors = { ink: { DEFAULT: '...', 2: '...' } }`。
**不要**在组件里写 `#3b82f6` 这种裸色值——`grep` 一次就该清零。

## 九、暗色推导（不是反色）

1. 中性 ramp 反转：页面底用 950–900 档的近似值（`#0f1115` 一类），**不要纯黑**。
2. 文字用 alpha 派生：`--ink: rgb(255 255 255 / .92)`，次级 `.68`，弱化 `.46`。
3. 品牌色提亮到 400 档（500 档在深底上对比不足）；浅色底纹改用 `--brand` + 12–16% alpha。
4. 阴影失效：改用 1px 边框（`rgb(255 255 255 / .08)`）+ 背景明度差。
5. 图片降亮度 `filter: brightness(.9)`；纯白插画必须换深色版。
6. 两套主题各跑一次 `contrast_check.py` 与 `audit.mjs --themes light,dark`——深色是独立问题。

## 十、验收

```bash
python scripts/contrast_check.py src/styles/tokens.css
node scripts/audit.mjs --url http://localhost:5173/ --themes light,dark
node scripts/scaffold.mjs --persona editorial --out .tmp/ui   # 先看看骨架再改
```

令牌层面的四条硬标准：**色值零裸写、间距无奇数、圆角 ≤4 档、阴影 ≤3 层**。
